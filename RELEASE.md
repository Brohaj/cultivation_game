# Путь Культиватора v0.7

Единственный вход — index.html. Текущая версия использует новый интерфейс, учеников, новую карму, улучшенные награды царств и исправленную паузу. Игра запускается без установки.

Один текущий профиль. При первом запуске без текущего сохранения прежний профиль переносится автоматически; новая игра не восстанавливает старый профиль после перезагрузки. Штатные импорт и экспорт сохраняют учеников, карму, награды похода и паузу.

Проверено:308 проверок логики и55 браузерных сценариев текущего интерфейса; ошибок страницы нет. Подробности интерфейса — docs/ui_v2.md, механики — docs/prototype_report.md.
