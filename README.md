# Путь Культиватора

Игра о культивации, походах и долгой жизни в мире сянься.

## Запуск

Распакуйте архив целиком и откройте **index-v2.html** в современном браузере. Это актуальный интерфейс для тестирования. Подключение к интернету и установка зависимостей для игры не требуются.

`index.html` содержит первую версию интерфейса. У каждой версии отдельное сохранение в браузере; при первом запуске V2 копирует имеющийся прогресс первой версии. Перенести прогресс в другой браузер можно через экспорт и импорт в настройках.

## Проверка

Для первого прогона используйте новое сохранение. Проверьте понятность первых действий, удобство интерфейса на ПК, походы, заточку, прорывы и рассеивание культивации. Замечания удобно записывать со скриншотом и размером окна; для игровых ошибок приложите экспорт сохранения.

Автоматические проверки для разработки: после `npm ci` запустите `npm test`, `npm run test:ui-v2` и `npm run test:scenery`. Для браузерных проверок нужен Chromium Playwright (`npx playwright install chromium`).

История изменений — в [CHANGELOG.md](CHANGELOG.md), описание интерфейса — в [docs/ui_v2.md](docs/ui_v2.md).
