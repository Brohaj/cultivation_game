# Путь Культиватора

Браузерная idle-игра о культивации, походах и долгой жизни в мире сянься.

## Запуск

Скачайте проект целиком и откройте **index.html** в современном браузере. Подключение к интернету и установка зависимостей для игры не требуются.

Прогресс сохраняется в браузере. Для переноса на другое устройство используйте экспорт и импорт в настройках игры.

## Разработка

После `npm ci` запустите `npm test` для логики и `npm run test:browser` для интерфейса. Браузерным проверкам нужен Chromium Playwright (`npx playwright install chromium`).

История изменений — в [CHANGELOG.md](CHANGELOG.md).
