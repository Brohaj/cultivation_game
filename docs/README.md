# Документация «Пути Культиватора»

Основная версия игры — **v0.7**, вход — [index.html](../index.html). Начните с [README проекта](../README.md), если хотите запустить игру, и с [CLAUDE.md](../CLAUDE.md), если хотите понять устройство проекта и порядок проверок. Описания «отдельного прототипа» в старых файлах относятся к этапам разработки: выбранные механики вошли в v0.7. При расхождении старых таблиц с текущей игрой сверяйтесь с кодом и тестами.

## Актуально для v0.7

| Файл | Что в нём |

| [prototype_report.md](prototype_report.md) | Действующие правила учеников, кармических путей, царств и сохранений; название файла осталось от этапа прототипа. |
| [balance_thresholds.json](balance_thresholds.json) | Контрольные диапазоны четырёх жизней для проверки баланса в CI. |

| [content_guide.md](content_guide.md) | Правила написания событий и приключений. |
| [worldbuilding.md](worldbuilding.md) | Канон мира и тон новых текстов. |

## Рабочие справочники с историческими разделами

Эти файлы полезны для поиска системы или обсуждения изменений, но часть чисел и формулировок относится к прежним версиям. Для действующих правил сначала смотрите документы v0.7 выше.

| Файл | Что в нём |
|---|---|
| [architecture.md](architecture.md) | Карта модулей базовой игры; вступление описывает прежний отдельный прототип. |
| [mechanics.md](mechanics.md) | Большой справочник механик и формул с историческими срезами. |
| [game_balance.md](game_balance.md) | Таблицы баланса и контрольные сценарии разных этапов. |
| [backlog.md](backlog.md) | Выполненные решения и оставшиеся идеи, затем история более ранних проходов. |
