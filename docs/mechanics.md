## Характеристики

| Стат | Что делает | Как растёт |
|------|-----------|-----------|
| **Сила** | Боевая мощь в событиях, множитель ци (+2%/ед), шанс прорыва (+0.3%/ед), снижение потерь при провале прорыва | Тренировка "Закалка Тела" + прорыв реалма (+2) + события |
| **Дух** | Множитель ци (+5%/ед), скорость XP техник | Тренировка "Постижение Дао" + прорыв реалма (+2) + события |
| **Удача** | Шанс прорыва (+1.5%/ед), качество наград (+1%/ед, нерфнуто с 2%), частота наградных событий | Тренировка "Испытание Судьбы" + события |

### Формулы влияния
```
Боевая мощь = floor((strength + artifactStrength + artifactCombatPower) * (1 + techBonus("combatPower")) * (1 + sectBonus("combatPower")) * bodyMult)
Множитель духа = 1 + (spirit + artifactSpirit) * 0.05
Множитель силы = 1 + strength * 0.04
Снижение потерь при провале = min(50%, strength * 0.5%)
Шанс прорыва (realm 3+) = (0.70 - realmPenalty) + sqrt(luck)*0.006 + techBonus + artifactBonus + sectBonus + formationBonus + bodyBonus + pillBonus   (min 1%, cap 95%)
pillBonus = от духовных пилюль (+5% каждая, кап +25%, расходуется при попытке)
Бонус удачи к наградам = luck * 1% (нерфнуто с 2%/ед, дополнительные камни/пилюли от reward-событий и экспедиций)
Бонус удачи к весу наградных событий = 1 + luck * 0.01 + techLuckBonus * 0.5
```

## Система ци

### Ци в секунду (только при активности "Медитация")
```
base = 5 + realmIndex * 3
qiPerSec = max(1, floor(base * spiritMult * strengthMult * qiMult * techQiMult * formationMult * artifactMult * sectMult * treasuryMult * elemMult))

spiritMult = 1 + (spirit + artifactSpirit) * 0.05
strengthMult = 1 + strength * 0.04
qiMult = rootMult × eraMult × worldEventMult × karmaMult
techQiMult = 1 + getTechBonus("qi")
formationMult = 1 + getFormationBonus("qi")
artifactMult = 1 + getArtifactBonus("qi") * 0.01
sectMult = 1 + getSectBonus("qi")
treasuryMult = 1 + log10(stones) * 0.08
elemMult = элементальный резонанс (корень + техники)
```
Игра полностью idle — кнопка клика удалена, все бонусы ци унифицированы под ключ `qi`.

### Множители ци (разбивка)
Каждый множитель виден в UI:
- **База**: 2 + realmIndex
- **Дух**: ×(1 + spirit × 0.05)
- **Сила**: ×(1 + strength × 0.02)
- **Корень**: ×qiMultiplier (0.8–1.5 в зависимости от типа)
- **Эпоха**: ×qiMultiplier (0.9–1.3)
- **Мир. событие**: ×qiMultiplier (если есть)
- **Техники**: ×(1 + сумма бонусов qiPerClick)
- **Формации (перманент.)**: ×(1 + getFormationBonus("qiPerClick"))
- **Артефакты**: ×(1 + getArtifactBonus("qiPerClick") × 0.01)
- **Секта**: ×(1 + getSectBonus("qiPerClick"))
- **Формация (старая)**: ×(1 + formationLevel × 0.25) — только для авто-ци
- **Техники (авто)**: ×(1 + qiPerSec бонус) — только для авто-ци

## Система активностей

4 тренировки, игрок выбирает одну активную. **Все 3 стата качаются пассивно (15%)**, активный стат — на 100%.

| Активность | Что растёт | Скорость | Пассивные статы |
|---|---|---|---|
| **Медитация** | Ци | qiPerSec | Все 3 стата на 15% |
| **Закалка Тела** | Сила (100%) | statXpPerTick | Дух, удача на 15% |
| **Постижение Дао** | Дух (100%) | statXpPerTick | Сила, удача на 15% |
| **Испытание Судьбы** | Удача (100%) | statXpPerTick | Сила, дух на 15% |

### Формула XP стата за тик
```
statXpPerTick = 1.0 * level^0.7 * (1 + realmIndex * 0.15) * karmaMult
karmaMult = 1 + statSpeedLevel * 0.05  // "Совершенствование": +5% множитель духа за уровень
```
Бонусы от формаций, секты, артефактов и техник НЕ влияют на скорость XP статов (statXpSpeed убран из statXpPerTick).

**Совершенствование (statXpSpeed)** — больше не ускоряет прокачку статов. Теперь умножает значение духа (включается в getSpiritMultiplier через perfBonus).

### XP до следующего уровня стата
```
statXpNeeded = floor(baseCost * level * 1.05^level)
baseCost: сила/дух = 5, удача = 8
```

При заполнении XP бара: стат +1, XP сбрасывается, лог в хронику.

### Взаимодействие с автокультивацией
- Авто работает на **текущей** активности
- Если активность = "meditation" → ци растёт
- Если активность = стат → XP стата растёт каждый тик
- Стоимость включения авто: 10 камней (разовая)

## Техники (Jobs)

### Прокачка через XP (не за камни!)
Экипированные техники **пассивно** набирают XP каждый тик (1 сек), независимо от активности.

### XP формулы
```
techXpNeeded = floor(TIER_XP_BASE[tier] * level * 1.2^level)
techXpPerTick = 1.0 * (1 + spirit * 0.02) * elementBonus
```

| Tier | Base XP | Макс уровень | Множитель эффектов |
|------|---------|-------------|-------------------|
| common | 30 | 5 | ×1 |
| uncommon | 60 | 8 | ×1.5 |
| rare | 120 | 10 | ×2.5 |
| epic | 250 | 12 | ×4 |
| legendary | 500 | 15 | ×7 |
| divine | 1000 | 20 | ×12 |

### Элементная совместимость
Если элемент техники совпадает с элементом духовного корня:
- XP скорость ×1.25
- Эффекты ×1.25

### Эффекты техник
| Эффект | Применение |
|--------|-----------|
| `qi` | Множитель к ци/сек (единый ключ, клик удалён) |
| `combatPower` | Множитель к боевой мощи |
| `breakthroughBonus` | Бонус к шансу прорыва |
| `luck` | Бонус к шансу прорыва, весу наградных событий, бонусу наград |
| `timeSpeed` | Ускорение течения времени (перезапуск таймеров при изучении/прокачке) |
| `qiRetention` | Удержание ци при провале прорыва |
| `lifespan` | Увеличение максимального возраста |
| `statXpSpeed` | Множитель духа (увеличивает spirit для расчёта getSpiritMultiplier) |
| `techXpSpeed` | Ускорение прокачки техник |

### Формула бонуса техники
```
techBonus(key) = sum(effect[key] * level * TIER_MULTIPLIERS[tier] * affinityMult)
```
Суммируется по всем экипированным техникам.

### Слоты техник
Только **экипированные** техники дают бонусы и качаются. Неэкипированные сохраняют прогресс XP.

| Реалм | Базовые слоты |
|-------|-------|
| 0-1 | 2 |
| 2-3 | 3 |
| 4-6 | 4 |
| 7-9 | 5 |
| 10+ | 6 |

Кармическое улучшение **"Расширение Сознания"** даёт +1 слот за уровень (макс 5 уровней).

При изучении новой техники она автоматически экипируется, если есть свободный слот.
При перерождении экипированные техники сбрасываются вместе с изученными.

### Пример прогрессии
**basic_breathing** (common): +2% qiPerClick/ур × ×1 = +10% на 5 ур
**six_paths_breathing** (legendary): +3% qiPerClick/ур × ×7 = +315% на 15 ур

## Прорыв

### Условия
- Ци >= qiNeeded()
- Не на максимальном реалме

### Механика
- **Реалм 0-2**: прорыв 100% успех
- **Реалм 3+**: есть шанс провала

### Формула шанса
```
Realm < 3: 100% (гарантирован)
Realm 3+:
  realmPenalty = mortalSteps * 0.10 + immortalSteps * 0.15
    mortalSteps = min(realmIndex - 3, 7)    // реалмы 3-9
    immortalSteps = max(0, realmIndex - 10) // реалмы 10+
  subLevelPenalty = (subLevel - 1) * 0.025  // sub 1 = 0%, sub 2 = -2.5%, sub 3 = -5%, sub 4 = -7.5%
  baseChance = 0.70 - realmPenalty - subLevelPenalty
  chance = baseChance + sqrt(luck)*0.012 + sqrt(spirit)*0.009 + sqrt(strength)*0.005
           + techBonus + artifactBonus + sectBonus + formationBonus + bodyBonus
  chance = max(0.01, min(chance, 0.95))
```
Хардкапов по реалмам нет — единый коридор 1%-95%. Шанс дополнительно снижается на **-2.5% за каждый подуровень** внутри реалма (sub 1 = 0%, sub 4 = -7.5%).

### При провале
- **Ци**: потеря baseLoss × (1 - totalReduction). Без удержания = потеряно всё
- **Дао прогресс**: потеря baseLoss × (1 - totalReduction). Формула идентична ци, qiRetention защищает оба ресурса
- **Статы** (realm 7+): -1 сила, -1 дух (realm 10+: -2). Удержание может защитить (шанс)
- **Страховка прорыва** (покупается за камни): полностью отменяет все потери (одноразово)
- **Удержание ци**: сумма техник + артефактов + секты + тела (макс 95%)

### При встрече с демоном (дополнительно к провалу)
- **Failsafe**: 1 раз в жизнь первая встреча с демоном автоматически отражается (`flags.demonFailsafeUsed`). Сбрасывается при перерождении
- Откат реалмов (1-4), сброс subLevel
- Потеря статов (сила/дух/удача)
- Потеря уровней Дао (реалмы - 1)
- Снятие лишних экипированных техник (если слоты уменьшились)

### При успехе
- Ци сбрасывается в 0
- Подуровень +1, или реалм +1 (subLevel сбрасывается на 1)
- При смене реалма: +2 сила, +2 дух
- При переходе mortal→immortal: особое сообщение

## События

### Тиры событий по реалмам
| Тир | Реалмы | Тематика | Примеры |
|-----|--------|----------|---------|
| Смертный | 0-3/5 | Деревня, рынок, лес | Травник, бандиты, звери, караван |
| Средний | 4-7/8 | Секты, руины, формации | Аукцион, демонические звери, дуэли |
| Высший | 8-9 | Трибуляции, демон-лорды | Небесная кара, пространственные трещины |
| Бессмертный | 10+ | Войны бессмертных, Дао | Божественные артефакты, Небесный Дворец |

### Приоритет триггера (каждые 15 сек)
1. **Цепочки событий** — если условие выполнено, шанс 30%
2. **Встречи с персонажами манхвы** — шанс 2-4% (очень редко)
3. **Обычные события** — взвешенный рандом по эпохе и мировым событиям

### Веса событий
```
weight = 1
if danger: weight *= era.dangerWeight * worldEvent.dangerWeight
if reward: weight *= era.rewardWeight * worldEvent.rewardWeight
```

### Цепочки событий
3 цепочки по 3-5 шагов:
- **Загадочный Торговец** (3 шага): встреча → сделка → награда
- **Наследие Древнего** (5 шагов): улика → след → загадка → страж → сокровище
- **Кризис Секты** (4 шага): слухи → расследование → конфронтация → итог

Прогресс через `game.flags`. Минимум N лет между шагами.

### Встречи с персонажами манхвы
5 редких пасхалок. Мы — никто, они нас не замечают. Подчёркивает масштаб мира.

| **Страховка Прорыва** | 50 + realmIndex × 20 | Следующий провал прорыва не отнимет ци (одноразово) |

### Пилюли (4 тира)

| Тир | Название | Эффект | Рефайн |
|-----|----------|--------|--------|
| 1 | Пилюля Ци | +500 ци (фикс) | — |
| 2 | Очищенная | +5,000 ци | 5 базовых + 5 пыли |
| 3 | Духовная | +50,000 ци, +8% дао, +5% к прорыву (кап +25%) | 5 очищенных + 20 пыли |

- **Без diminishing** — эффективность не падает от использования

- **Рефайн гейты**: тир 2→3 и 3→4 могут требовать вознесение тела Алхимика
- **Алхимик**: рефайн 4:1 вместо 5:1, ★3 — авто-рефайн
- **Источники**: события, экспедиции, приключения, карма, секта (пожертвование)
- **Массовое использование**: x1/x10/x100 кнопки (usePillMulti, refinePillMulti)
- **UI**: компактная таблица — 1 строка на тир (название, кол-во, использование, рефайн)

- Новые секретные (13): скрытые достижения

### Категории (7)
| Категория | Иконка | Примеры |
|-----------|--------|---------|
| Культивация | ☯ | Реалмы, медитации, техники, статы, возраст |
| Бой | ⚔ | Боевая мощь, победы, демон |
| Секта | ⛩ | Вступление, ранги, задания, Дао, посещение сект |
| Исследование | ✈ | Экспедиции, камни, приключения |
| Артефакты | 💍 | Находки, заточка, трансценд, снаряжение |
| Перерождение | ♾ | Перерождения 1/3/5/10 |
| Секреты | ☠ | Выживание, естественная смерть, все события перерождения |

### Награды достижений
Бонусы применяются перманентно между жизнями.

| Тир | Награда | Условие | Заметки |
|-----|---------|---------|---------|
| Бронзовые | +1% карма каждое | Только после первого перерождения | — |
| Серебряные | +1% карма каждое | Только после первого перерождения | — |
| Золотые | +1% карма каждое | Только после первого перерождения | — |
| Нефритовые | +2% скорость Дао каждое | — | — |
| Секретные | +5% скорость Дао каждое | — | — |

Максимальный бонус кармы от бронзовых/серебряных/золотых: **+50%** (при 50 достижениях этих тиров).

Функция `getDaoSpeedMultiplier()` в `formulas.js` рассчитывает суммарный множитель скорости Дао:
```
daoSpeedMult = (1 + techBonus("daoSpeed")) * (1 + jadeMilestones * 0.02 + secretMilestones * 0.05)
```
Используется во всех источниках Дао: тик, пожертвования, экспедиции, приключения.

- Незалоченные показывают название и описание (кроме тира "Секретные" — те показывают "???" пока не получены)
- Фильтры по тирам вверху таба
- Группировка по категориям с иконками и счётчиками
- Перманентны между жизнями (`prestige.permanentMilestones`)

## Артефакты

Экипируемые предметы с бонусами. Дропаются из событий и тайных царств. 4 слота экипировки.

### Тиры артефактов (унифицированные названия)

Все системы (техники, артефакты, духовные корни, экспедиции) используют единую шкалу тиров:
**Смертный / Духовный / Мистический / Небесный / Священный / Божественный**

| Тир | Название | Множитель | Макс. уровень | Шанс дропа |
|-----|----------|-----------|--------------|-----------|
| common | Смертный | ×1 | 3 | 50% |
| uncommon | Духовный | ×1.5 | 5 | 25% |
| rare | Мистический | ×2.5 | 8 | 15% |
| epic | Небесный | ×4 | 10 | 7% |
| legendary | Священный | ×7 | 12 | 2.5% |
| divine | Божественный | ×12 | 15 | 0.5% |

### Слоты экипировки
| Слот | Основные бонусы | Редкий бонус (epic+, ~10-15%) |
|------|----------------|-------------------------------|
| Оружие | +сила, +боевая мощь, +ци, +награда за опасность | — |
| Броня | +удержание ци, +долголетие, +дух, +эффект пилюль | снижение демонов |
| Аксессуар | +дух, +удача, +ци, +шанс прорыва, +карма | скорость времени |
| Сокровище | +ци, +уклонение, +XP техник, +доход камней, +множитель духа | скорость экспедиций |

### Генерация
- 1-2 эффекта из пула слота (2 для epic+)
- Значения = (min..max) × tier_mult

### Нейминг (PoE-стиль)
**1 стат (common-rare):** `[Тир-Префикс] [База] [Суффикс стата]`
  - Пример: "Грозовой Меч Силы", "Нефритовая Роба Духа"

**2 стата (epic+):** `[Стат-Аффикс] [База] [Суффикс 2го стата]`
  - Аффикс определяется первым статом и тиром (epic/legendary/divine — разные слова)
  - Пример epic: "Разящий Клинок Удачи" (strength + luck)
  - Пример legendary: "Сокрушительная Секира Мощи" (strength + combatPower)
  - Пример divine: "Вознесённая Диадема Времени" (spirit + timeSpeed)

### Заточка (BDO-стиль)
- 10 уровней улучшения (+1..+10)
- Каждый уровень: ×1.2 к эффектам (экспоненциально: +5=×2.5, +10=×6.2)
- Шанс падает: +1=90%, +5=45%, +7=25%, +10=8%
- Провал: +1..+3 без даунгрейда, +4..+6 — 50%, +7..+10 — гарантированный даунгрейд
- Failstacks: +2% за каждый провал, накапливаются

### Слияние (Transcend, PRI-PEN)
- Два артефакта одного уровня слияния → следующий уровень
- PRI(×2) → DUO(×3) → TRI(×4) → TET(×6) → PEN(×8)
- Первое слияние требует оба артефакта на +10

### Массовый разбор
- Кнопка "Разобрать..." открывает центрированный попап со списком тиров
- Каждый тир показан строкой с цветом тира: количество артефактов + суммарная пыль/эссенция
- Пропускаются экипированные и улучшенные (+1+) артефакты
- Enter подтверждает, Escape отменяет

### При перерождении
- Все артефакты **сбрасываются**
- Кармическое улучшение "Память Артефактов" сохраняет 1 лучший артефакт

## Секты и Пути Дао

Каждая секта = Путь Дао. Вступление даёт Путь Дао (бонусы/дебаффы) + 2 формации (разблокировка перманентна).

### 5 Сект

| Секта | Путь Дао | Требование | Доступ |
|-------|----------|-----------|--------|
| Нефритовая Чистота | Путь Воды (水道) | Реалм 1 | Первая жизнь |
| Орден Алого Пламени | Путь Меча (剑道) | Реалм 3 + win_combat | Первая жизнь |
| Лунное Озеро | Путь Алхимии (丹道) | Реалм 3 + hundred_med | Первая жизнь |
| Культ Бездны | Путь Пустоты (虚道) | Реалм 5 + 2 перерождения | С 3-й жизни |
| Скрытая Секта | Путь Свободы (逍遥道) | Реалм 7 + 3 перерождения | С 4-й жизни |
### Пути Дао (5 путей)

| Путь | Секта | Описание |
|------|-------|----------|
| Путь Воды (水道) | Нефритовая Чистота | Гармония, текучесть |
| Путь Меча (剑道) | Орден Алого Пламени | Клинок, воля |
| Путь Алхимии (丹道) | Лунное Озеро | Трансмутация, мудрость |
| Путь Пустоты (虚道) | Культ Бездны | Небытие, поглощение |
| Путь Свободы (逍遥道) | Скрытая Секта | Независимость, странствие |

Каждый путь имеет **28 уникальных уровней** с собственными названиями и философскими описаниями на каждом уровне.

### Дао — механика

- **Дао бар** (0-100%) — второй бар помимо ци, появляется с реалма 3
- Для прорыва реалма: ци ≥ 100% И дао ≥ 100%
- Для подуровня: только ци
- Уровень Дао = сколько раз заполнил бар (= макс уровень формаций этой секты)
- **Кап Дао**: daoLevel ограничен requiredDao + 4 (нельзя перекачать больше чем на 4 уровня сверх текущего требования прорыва)
- Дебаффы уменьшаются с каждым уровнем Дао → на макс уровне превращаются в бонусы

### Прогрессивные требования Дао

```
Уровни 1-8 (линейная прогрессия):
  daoNeeded = 80 + daoLevel × 20

Уровни 9+ (экспоненциальная прогрессия):
  daoNeeded = round_to_50((80 + daoLevel × 20) × exp((daoLevel - 8) × 0.25))
```

### Давление Дао (Дао Прессинг)

На высоких уровнях Дао при провале прорыва увеличивается **порог** срабатывания Внутреннего Демона (вместо добавления плоского % к шансу):

| Уровень Дао | Порог демона |
|-------------|-------------|
| 1-8 | 65% (базовый) |
| 9-16 | 70% (+5%) |
| 17-24 | 75% (+10%) |
| 25+ | 80% (+15%) |

Демон появляется если шанс прорыва < порога. Отображается в тултипе демона как "Давление Дао".

### Потеря Дао при провале прорыва

При провале прорыва (не демон) `daoProgress` теряется по той же формуле, что и ци:
```
daoLoss = daoProgress × (1 - totalReduction)
totalReduction = qiRetention (из техник + артефактов + секты + тела)
```
`qiRetention` защищает и ци, и Дао одновременно.

### Активность для Дао (по секте)

| Секта | Какая тренировка качает Дао | Логика |
|-------|---------------------------|--------|
| Нефрит | Постижение Дао (дух) | Гармония через созерцание |
| Пламя | Закалка Тела (сила) | Дао через бой |
| Озеро | Постижение Дао (дух) | Мудрость алхимика |
| Бездна | Закалка Тела ИЛИ Испытание Судьбы | Сила + риск |
| Скрытая | Любая из трёх (×0.5) | Свобода = без специализации |

Медитация НИКОГДА не качает Дао.

| Ранг | Вклад | Множитель бонусов |
|------|-------|-------------------|

3 слота заданий с раздельным кулдауном по рангу (Внешний=12 лет, Внутренний=10, Ядровой=8, Старейшина=6, Глава=6 лет). Типы: сдать камни, убить зверя (combatPower check), медитировать N лет, сдать пилюли/пыль/эссенцию, боевые испытания.

Разблокировка по рангу: `minRank: 1` (Внутренний+), `minRank: 2` (Ядровой+), `minRank: 3` (Старейшина+), `minRank: 4` (Глава Секты).

- Прогресс XP секта-техник теряется

- Секта **сбрасывается** (ранг и вклад теряются)
- Можно выбрать ту же или другую секту

## Приключения

Параллельная система квестов с выбором. Не прерывает основной геймплей.

### Поток
1. Случайное событие генерирует **слух** → появляется в табе "Приключения"
2. Игрок **принимает** приключение (макс 1 активное, макс 5 слухов)
3. Каждый шаг: текст + **2-3 варианта** (разная длительность/стоимость/проверка стата)
4. Провал проверки не блокирует — даёт ослабленный результат или штраф
5. Финальный шаг определяет награды на основе накопленных флагов
6. Непринятые слухи истекают через 100 лет

## Взаимосвязи систем

```
Духовный корень ──────┬──→ Множитель ци (постоянный)
                      └──→ Бонус к технике (элемент совпадает: ×1.25)

Дух ──────────────────┬──→ Множитель ци за клик (×(1 + spirit*0.05))
                      ├──→ Скорость XP техник (×(1 + spirit*0.02))
                      └──→ Шанс прорыва (+0.5% за единицу)

Сила ─────────────────┬──→ Боевая мощь → исход опасных событий
                      ├──→ Множитель ци за клик (×(1 + strength*0.02))
                      ├──→ Шанс прорыва (+0.3% за единицу)
                      └──→ Снижение потерь при провале прорыва (до -50%)

Удача ────────────────┬──→ Шанс прорыва (+1.5% за единицу)
                      ├──→ Качество наград (+2% за единицу)
                      └──→ Частота наградных событий (+1% к весу за единицу)

Техники ──────────────┬──→ Бонусы к ци клик (qiPerClick)
                      ├──→ Бонусы к ци авто (qiPerSec — множитель только для авто-ци)
                      ├──→ Бонусы к бою (strength, combatPower, defense)
                      ├──→ Бонус к прорыву (breakthroughBonus)
                      ├──→ Уклонение от danger-событий (dodgeChance)
                      ├──→ Восстановление ци после событий (healOnEvent)
                      └──→ Бонус удачи (luck → прорыв, награды, частота)

Камни ────────────────┬──→ Автокультивация (10, разово)
                      ├──→ Усиление формации (старая, +25% авто-ци/ур)
                      ├──→ Свиток Озарения (мгновенный XP техник)
                      ├──→ Страховка прорыва (отмена потери ци)
                      ├──→ Культ. Формации (перманентные множители)
                      └──→ Улучшение артефактов

Артефакты ────────────┬──→ Бонусы к ци, бою, прорыву, XP
                      └──→ Сбрасываются при перерождении

Формации (перманент.) ┬──→ +% ци/клик, множитель духа, XP техник, удача
                      └──→ -% время экспедиций

Секта ────────────────┬──→ Бонусы к ци, бою, пилюлям, XP (× ранг)
                      ├──→ Уникальная техника секты
                      ├──→ Задания → вклад → ранги
                      └──→ Сбрасывается при перерождении

Экспедиции ───────────┬──→ Камни, пилюли, артефакты, техники (шанс)
                      └──→ Таймер по passYear()

Приключения ──────────┬──→ Слухи из событий → принять → шаги с выбором
                      ├──→ 2-3 варианта на каждом шаге (стоимость/проверка/длительность)
                      ├──→ Макс 2 активных, 5 слухов, истечение 100 лет
                      └──→ Сбрасывается при перерождении

Эпоха ────────────────┬──→ Множитель ци
                      └──→ Веса событий (danger/reward)

Мировое событие ──────┬──→ Множитель ци
                      ├──→ Веса событий
                      ├──→ Эффект пилюль
                      └──→ Доход камней

Реалм ────────────────┬──→ База ци за клик (+1 за реалм)
                      ├──→ Требования ци для прорыва
                      ├──→ Макс. возраст (продолжительность жизни)
                      ├──→ Слоты техник (2→6)
                      ├──→ Доход камней (+0.5/год за реалм)
                      └──→ Доступные события (фильтр по condition)
```

### Петля прогрессии
```
Медитация → ци → прорыв → новый реалм → больше базовой ци + слоты техник
                                          ↓
Тренировка → статы ↑ → больше ци/клик, лучше бои, выше шанс прорыва
                                          ↓
Техники (пассивный XP) → уровень ↑ → множители ↑ → ускорение всего
                                          ↓
Секта → бонусы × ранг → задания → вклад → повышение → больше бонусов
                                          ↓
Экспедиции → камни + артефакты → формации (перманент.) + экипировка → ещё быстрее
                                          ↓
Перерождение → карма + тела + формации → новый цикл с бонусами
```

## Таймеры

| Интервал | Функция | Что происходит |
|----------|---------|----------------|
| 1 сек | `tick()` | Авто-ци или авто-XP стата, пассивный XP техник |
| 5 сек | `passYear()` | +1 год, доход камней, смена эпох, мировые события, проверка смерти |
| 15 сек | `triggerEvent()` | Случайное событие (цепочки → манхва → обычные, 50% шанс пропуска) |
| 30 сек | `autoSave` | Сохранение в localStorage (+ при beforeunload и паузе) |

Все интервалы масштабируются `getSpeedMultiplier()` = `1 + karmaTimeFlow * 0.25 + techTimeSpeed + artifactTimeSpeed`. `refreshTimers()` пересчитывает при изучении/прокачке техник с `timeSpeed` или экипировке артефактов.

Debug-режим: множитель `debugSpeed` (x1/x10/x100) ускоряет все тики пропорционально.

### Таймер смерти
Опциональный переключатель в настройках (`game._showDeathTimer`). Показывает оставшееся время до maxAge в формате часы:минуты:секунды с учётом текущей скорости игры.

### Хроники (лог событий)

- Все игровые события записываются в лог ("Хроники") в правой панели
- Каждая запись содержит временную метку: `[X г.] текст`
- **Переключатель времени** (кнопка "Мир"/"Возраст" в заголовке):
  - **Мир** (по умолчанию): показывает мировой год (`game.years`)
  - **Возраст**: показывает возраст персонажа (`game.characterAge()`)
- Каждая запись лога сохраняет оба значения в `data-worldYear` и `data-charAge`
- Максимум 150 записей, старые удаляются автоматически
- **Не логируются**: апгрейды формаций, использование пилюль, переключение активностей, разбор артефактов (одиночный и массовый), повышение уровня статов, повышение уровня техник (кроме максимального), выполнение заданий секты (награда Дао)
- При достижении техникой максимального уровня выводится "достигла максимума! Вознесение доступно." вместо номера уровня
- Достижения логируются только при **первом** получении (не при повторном достижении в новой жизни)

## Перерождение (Prestige)

Система перерождения — NG+ механика, вдохновлённая Realm Grinder и Progress Knight Quest. При смерти или добровольно (реалм 9+) игрок перерождается, сохраняя постоянные бонусы.

### Карма (престиж-валюта)

Начисляется за прогресс текущей жизни:
```
karma = realmIndex * 5
      + floor(characterAge / 100) * 2
      + techniques.length * 3
      + milestones.length * 2
      + totalBreakthroughs
      + sectRankIndex * 3                         // бонус от ранга секты
      + floor(sect.contribution / 100)            // бонус от вклада секты
karma *= (1 + body.karmaBonus + bodyAsc.karmaBonus)  // бонус от тела (0–100%)
karma *= sectKarmaMultiplier                      // множитель секты (Культ Бездны)
karma *= 1.5  // только при естественной смерти — "Мудрость Полной Жизни"
```

**Масштабирование стоимости улучшений:**
```
upgradeCost(level) = baseCost * (1 + level * 0.5)
```
Каждый следующий уровень дороже на 50% от базовой стоимости.

### Что сохраняется между жизнями
- **Карма** — накапливается (не сбрасывается)
- **Достижения** — перманентны (permanentMilestones)
- **Кармические улучшения** — постоянные бонусы
- **Счётчик перерождений** — totalRebirths
- **Вознесения тел** — bodyAscensions
- **Культивационные Формации** — prestige.formations
- **Мировое время** — мир продолжает жить (worldAge)

### Что сбрасывается
- Ци, реалм, подуровень
- Статы (сила, дух, удача) → базовые + бонусы от тела и кармы
- Ресурсы (камни, пилюли) → бонусы от тела и кармы
- Техники → только стартовые от тела
- Флаги событий и цепочек
- Секта (ранг и вклад теряются)
- Экспедиция
- Артефакты (кроме сохранённых "Памятью Артефактов" и перенесённых Воином)
- Пыль/эссенция (кроме переноса Алхимика)
- Failstacks (кроме переноса Кузнеца)

### Межжизненные синергии (Cross-Life Loops)

Тела создают стратегические циклы между перерождениями:

```
Воин (экспедиции → артефакты)
  ↓ передаёт артефакты (★1+)
Алхимик (разбирает → пыль/эссенция)
  ↓ переносит пыль/эссенцию
Кузнец (затачивает, сохраняет failstacks)
  ↓ затачивает + создаёт PEN артефакты
Воин (экипирует → ещё экспедиции)
  ↓ ... цикл
```

### Добровольное перерождение — Рассеивание Культивации (散功)

Культиватор уровня **Махаяна** (реалм 9+) может сознательно рассеять свою основу, жертвуя текущую силу ради нового цикла.

- **Требование**: реалм 9 (Махаяна) или выше
- **Карма**: стандартная (без бонуса +50%)
- **Стратегия**: быстрые циклы для кармы vs дождаться смерти для бонуса

### Мудрость Полной Жизни

При **естественной смерти** карма увеличивается на **+50%**. Дилемма:
- Переродиться рано = больше циклов, быстрее тела/улучшения
- Прожить до конца = больше кармы за жизнь, но медленнее

### Поток перерождения
```
Смерть (естественная, +50% кармы) или Рассеивание Культивации (реалм 9+)
  → Расчёт кармы (реалм + возраст + техники + достижения + прорывы + секта)
  → Применение множителей (тело, секта, естественная смерть)
  → Модалка перерождения:
      ├── Разбивка заработанной кармы
      ├── Кармический магазин (улучшения с масштабируемой стоимостью)
      ├── Вознесение тел (покупка за карму)
      └── Выбор тела перерождения (сгруппированы по тирам)
  → Выполнение перерождения:
      ├── Достижения мержатся в permanentMilestones
      ├── totalRebirths++
      ├── Полный сброс (reset)
      ├── Перенос ресурсов (Алхимик: пыль/эссенция, Воин: артефакты, Кузнец: failstacks)
      ├── Применение бонусов тела (статы, ресурсы, техники, перки)
      ├── Применение вознесённых перков (if ascLevel > 0)
      ├── Применение кармических улучшений (+ бесплатные уровни Архата)
      ├── Формации от Древнего (если выбран)
      ├── Бесплатная страховка Фортуны (если выбран)
      └── Бросок нового духовного корня (с мин. тиром от тела/вознесения)
  → Начало новой жизни
```

### Взаимосвязи с другими системами
```
Достижения + Перерождения ──→ Разблокировка тел (тиры 0-6)

Тела ────────────┬──→ Стартовые статы/ресурсы/техники
                 ├──→ Уникальные перки (подключены к формулам)
                 ├──→ Мин. тир духовного корня
                 ├──→ Стартовый реалм
                 └──→ Множитель кармы

Вознесение тел ──┬──→ Усиленные перки (3 уровня)
                 └──→ Межжизненные синергии (передача ресурсов)

Карма ───────────┬──→ Кармические улучшения (масштабируемая стоимость)
                 ├──→ Вознесение тел
                 └──→ Небесный Барьер (гейт для реалмов 10+)
```
