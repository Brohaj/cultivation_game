## Характеристики

| Стат | Что делает | Как растёт |
|------|------------|------------|
| Сила | База боевой мощи; множитель медитации +3% за единицу до софткапа | Закалка Тела, прорыв реалма, события |
| Дух | Множитель медитации +6% за единицу до софткапа; +2% скорости XP техник | Постижение Дао, прорыв реалма, события |
| Удача | Шанс прорыва, частота наградных событий и ограниченный бонус добычи | Испытание Судьбы, события |

Сила и дух не увеличивают шанс прорыва. Бонус удачи к шансу равен sqrt(totalLuck) × 0.006. Бонус добычи = 0.5 × (1 − exp(−sqrt(totalLuck) × 0.16)), предел +50%. Эффекты техник strength/spirit усиливают множители медитации; боевой бонус техник задаётся отдельно ключом combatPower.

Боевая мощь = floor((strength + artifactStrength + artifactCombatPower) × (1 + techCombat) × (1 + sectCombat) × (1 + formationCombat) × bodyCombat). Подробная разбивка использует только экипированные техники и их общий эффект с ослаблением.

## Система ци

Ци начисляется автоматически при выбранной медитации, кроме времени в экспедиции. После возвращения прежняя активность продолжается. Ручного клика и покупки автокультивации нет.

```
base = 5 + realmIndex * 3
perf = 1 + softcap(formationPerf + sectPerf + artifactPerf + techPerf + (statSpeed + freeLevels) * 0.05, 3, 0.5)
spiritMult = (1 + softcap(spirit + artifactSpirit, eraStatCap, 0.5) * 0.06 + techSpirit) * perf
strengthMult = 1 + softcap(strength + artifactStrength, eraStatCap, 0.5) * 0.03 + techStrength
qiMult = rootMult * eraMult * worldMult * (1 + (enlightenment + freeLevels) * 0.05)
karmaMult = 1 + log10(max(1, karma + spentKarma)) * 0.15
qiPerSec = max(1, floor(base * spiritMult * strengthMult * qiMult * (1 + techQi) * (1 + formationQi) * (1 + artifactQi * 0.01) * (1 + sectQi) * karmaMult * elementalMult))
```

Элементальный резонанс даёт +12% за совпадение корня с экипированной техникой. Уровни формаций сбрасываются за жизнь; доступ к формациям сохраняется. Камни в кошельке не усиливают ци.

getMeditationQiPerSec() рассчитывает темп независимо от занятия; qiPerSec() возвращает 0 при других занятиях. Награды событий используют расчётный темп. На реалме 6+ награда ци ограничена max(600 секунд медитации, 10% исходной награды); на последней ступени вместо бесконечности используется конечная награда за 600 секунд.

## Система активностей

4 тренировки, игрок выбирает одну активную. **Все 3 стата качаются пассивно (15%)**, активный стат — на 100%.

| Активность | Что растёт | Скорость | Пассивные статы |
|---|---|---|---|
| **Медитация** | Ци | qiPerSec | Все 3 стата на 15% |
| **Закалка Тела** | Сила (100%) | statXpPerTick | Дух, удача на 15% |
| **Постижение Дао** | Дух (100%) | statXpPerTick | Сила, удача на 15% |
| **Испытание Судьбы** | Удача (100%) | statXpPerTick | Сила, дух на 15% |

### Формула XP стата за тик
```
statXpPerTick = 1.0 * level^0.7 * (1 + realmIndex * 0.15)
```
Бонусы от формаций, секты, артефактов и техник НЕ влияют на скорость XP статов (statXpSpeed убран из statXpPerTick).

**Совершенствование (statXpSpeed)** — больше не ускоряет прокачку статов. Теперь умножает значение духа (включается в getSpiritMultiplier через perfBonus).

### XP до следующего уровня стата
```
statXpNeeded = floor(baseCost * level * 1.05^level)
baseCost: сила/дух = 5, удача = 8
```

При заполнении XP бара: стат +1, оплаченный порог вычитается, остаток XP сохраняется. При нескольких уровнях каждый следующий оплачивается по своему порогу.

### Автоматическая работа активности

Активность действует автоматически с начала игры. Тик выполняется 5 раз/сек; скорости XP и ци умножаются на 1/5. В царстве не начисляются ци и годы медитации; XP статов и техник продолжается.

## Техники (Jobs)

### Прокачка через XP (не за камни!)
Экипированные техники **пассивно** набирают XP каждый тик (200 мс, скорость XP умножается на 1/5), независимо от активности.

### XP формулы
```
techXpNeeded = floor(TIER_XP_BASE[tier] * level * 1.2^level)
techXpPerTick = (1 + spirit * 0.02) * (1 + formationXP) * (1 + artifactXP * 0.01) * (1 + sectXP) * (1 + techXPBonus) * elementBonus * (1 + (talent + freeLevels) * 0.10)
```

| Tier | Base XP | Типичный исходный максимум | Силовые эффекты | Поддержка |
|------|---------|--------------------------|-----------------|-----------|
| common | 30 | 5 | ×1 | ×1 |
| uncommon | 60 | 8 | ×1.5 | ×1.25 |
| rare | 120 | 10 | ×2 | ×1.5 |
| epic | 250 | 12 | ×2.75 | ×1.8 |
| legendary | 500 | 15 | ×3.5 | ×2.1 |
| divine | 1000 | 20 | ×4.5 | ×2.5 |

Силовая кривая применяется к `qi`, `combatPower`, `strength`, `spirit`, `statXpSpeed`; остальные ключи используют поддержку. Процентные пункты прорыва, обучение, удержание и время растут медленнее силы. Исходный `maxLevel` задаётся самой техникой и не меняется при вознесении.

### Элементная совместимость
Если элемент техники совпадает с элементом духовного корня:
- XP скорость ×1.50
- Эффекты ×1.25

### Эффекты техник
| Эффект | Применение |
|--------|-----------|
| `qi` | Множитель к ци/сек (единый ключ, клик удалён) |
| `spirit` | Процентный бонус к множителю духа в расчёте ци; действует только при экипировке |
| `combatPower` | Множитель к боевой мощи |
| `breakthroughBonus` | Бонус к шансу прорыва |
| `luck` | Плоский бонус шанса прорыва: techBonus(luck) × 0.01; не входит в totalLuck наград |
| `timeSpeed` | Ускорение течения времени (перезапуск таймеров при изучении/прокачке) |
| `qiRetention` | Удержание ци при провале прорыва |
| `lifespan` | Увеличение максимального возраста |
| `statXpSpeed` | Множитель духа (увеличивает spirit для расчёта getSpiritMultiplier) |
| `techXpSpeed` | Ускорение прокачки техник |

### Формула бонуса техники
```
rawBonus = effect[key] * level * getTechniqueTierMultiplier(tier, key) * affinityMult
techBonus(key) = sum(sortedRawBonus[i] * weight[i])
weight = [1, 0.6, 0.4, 0.25, 0.15]; для i >= 5 вес = 0.15
```
`getTechniqueEffectBonus()` — общий источник величины для игры, карточки и разбора боевой мощи. По каждому ключу бонусы экипированных техник сортируются по убыванию и суммируются с указанным ослаблением.

### Слоты техник
Только **экипированные** техники дают бонусы и качаются. Неэкипированные сохраняют прогресс XP.

| Реалм | Базовые слоты |
|-------|-------|
| 0-1 | 2 |
| 2-3 | 3 |
| 4-6 | 4 |
| 7-9 | 5 |
| 10+ | 6 |

Расширение Сознания даёт +1 слот за покупной уровень (макс 5). Бесплатные уровни Архата добавляют слоты сверх этого; Эпоха Конфликта (год 300) открывает ещё один.

При изучении новой техники она автоматически экипируется, если есть свободный слот.
При перерождении экипированные техники сбрасываются вместе с изученными.

### Пример прогрессии

Базовая Техника Дыхания: 0.03 × 5 × 1 = +15% ци. Дыхание Шести Путей: 0.008 × 15 × 2.1 = +25.2 процентного пункта к шансу прорыва до элемента и ослабления. Сердце Бессмертного Дао: 0.035 × 20 × 4.5 = +315% ци, отдельный множитель ×4.15. Зеркало Сердца Дао, вознесённое в divine, на своём исходном максимуме 10 с подходящим корнем: 0.03 × 10 × 2.5 × 1.25 = +93.75% XP техник, множитель ×1.9375 до других источников. Тир при вознесении меняется, исходный maxLevel сохраняется; таблица выше показывает типичные исходные потолки, а не правило нового тира.

## Прорыв

### Условия
- Ци >= qiNeeded()
- Не на максимальном реалме; нет gameOver или pendingRebirth
- С реалма 3 нужна секта и daoLevel ≥ (realmIndex − 3) × 4 + subLevel для каждой попытки
- При переходе в реалмы 10+ выполнены условия Небесного Барьера; при блокировке ци сохраняется

### Механика
- **Реалм 0-2**: прорыв 100% успех
- **Реалм 3+**: есть шанс провала

### Формула шанса
```
Realm < 3: 100% (гарантирован)
Realm 3+:
  realmPenalty = mortalSteps * 0.10 + immortalSteps * 0.15
    mortalSteps = min(realmIndex - 3, 7)    // реалмы 3-9
    immortalSteps = max(0, realmIndex - 10) // реалмы 10+
  subLevelPenalty = (subLevel - 1) * 0.025  // sub 1 = 0%, sub 2 = -2.5%, sub 3 = -5%, sub 4 = -7.5%
  baseChance = 0.70 - realmPenalty - subLevelPenalty
  chance = baseChance + sqrt(totalLuck)*0.006
           + techBonus + techBonus("luck") * 0.01 + artifactBonus + sectBonus
           + formationBonus + bodyBonus + dreamBonus + pillBonus
  chance = max(0.01, min(chance, eraCap))  // 95%; с года 500 000 — 100%
```
Коридор 1%–95%, с Разрушения Дао (год 500 000) — 1%–100%. Шанс дополнительно снижается на **-2.5% за каждый подуровень** внутри реалма (sub 1 = 0%, sub 4 = -7.5%).

### При провале
- **Ци**: потеря baseLoss × (1 - totalReduction). Без удержания = потеряно всё
- **Дао прогресс**: потеря baseLoss × (1 - totalReduction). Формула идентична ци, qiRetention защищает оба ресурса
- **Статы** (realm 7+): -1 сила, -1 дух (realm 10+: -2). Удержание может защитить (шанс)
- **Удержание ци**: сумма техник + артефактов + секты + тела (макс 95%)

### При встрече с демоном (дополнительно к провалу)
- **Failsafe**: 1 раз в жизнь первая встреча с демоном автоматически отражается (`flags.demonFailsafeUsed`). Сбрасывается при перерождении
- Откат реалмов (1-4), сброс subLevel
- Потеря статов (сила/дух/удача)
- Потеря уровней Дао (реалмы - 1)
- Снятие лишних экипированных техник (если слоты уменьшились)

### При успехе
- Ци сбрасывается в 0
- Подуровень +1, или реалм +1 (subLevel сбрасывается на 1)
- При смене реалма: +2 сила, +2 дух
- При переходе mortal→immortal: особое сообщение

## Духовный корень

Корень принимается один раз за жизнь из доступного списка. В первой жизни доступен Обычный. Тело и вознесение могут гарантировать минимальный тир: корни этого тира доступны благодаря происхождению, более высокие — по обычным условиям; низшие не предлагаются. Элементы по умолчанию случайны; Выбор Элемента позволяет выбрать открытые через мастерство сект, без дублей и в пределах числа слотов. Повторное принятие корня не выдаёт стартовые статы снова.

| Корень | Открытие | Ци | Стартовые статы | Элементы |
| --- | --- | --- | --- | --- |
| Никакого | 3 завершённых перерождений | ×0.8 | +5 удачи | — |
| Обычный корень | С начала игры | ×1 | — | — |
| Двойной элемент | 1 завершённых перерождений | ×1.15 | +1 духа | 2 случайных |
| Тройной элемент | 2 завершённых перерождений | ×1.1 | +2 духа, +1 удачи | 3 случайных |
| Одиночный элемент | 2 завершённых перерождений, `realm_5` | ×1.25 | +2 духа | 1 случайных |
| Духовное Тело | 4 завершённых перерождений, `realm_9` | ×1.3 | +3 духа, +1 силы | 2 случайных |
| Хаотическое Тело | 7 завершённых перерождений, `immortal` | ×1.5 | +3 духа, +2 силы, +2 удачи | 6 случайных |

### Влияние на геймплей
- **Множитель ци**: постоянный множитель к qi
- **Элементы**: эффекты совместимых техник ×1.25, их скорость XP ×1.50
- **Стартовые статы**: бонусы применяются сразу при выборе

## События

### Тиры событий по реалмам
| Тир | Реалмы | Тематика | Примеры |
|-----|--------|----------|---------|
| Смертный | 0-3/5 | Деревня, рынок, лес | Травник, бандиты, звери, караван |
| Средний | 4-7/8 | Секты, руины, формации | Аукцион, демонические звери, дуэли |
| Высший | 8-9 | Трибуляции, демон-лорды | Небесная кара, пространственные трещины |
| Бессмертный | 10+ | Войны бессмертных, Дао | Божественные артефакты, Небесный Дворец |

### Приоритет триггера (база — каждые 15 сек)

1. Доступный следующий шаг цепочки: отдельный шанс 30%, при успехе выполняется сразу.
2. Иначе — 50% шанс пропустить событие.
3. После этого — 5% шанс проверить доступные встречи манхвы.
4. Иначе — обычное событие из доступного пула с весами эпохи, мирового события и удачи.

### Веса событий
```
weight = 1
if danger: weight *= era.dangerWeight * worldEvent.dangerWeight
if reward: weight *= era.rewardWeight * worldEvent.rewardWeight * (1 + rewardLuckBonus)
```

### Цепочки событий
3 цепочки по 3-5 шагов:
- **Загадочный Торговец** (3 шага): встреча → сделка → награда
- **Наследие Древнего** (5 шагов): улика → след → загадка → страж → сокровище
- **Кризис Секты** (4 шага): слухи → расследование → конфронтация → итог

Прогресс через `game.flags`. Минимум N лет между шагами.

### Встречи с персонажами манхвы
Редкие пасхальные встречи. Мы — никто, они нас не замечают. Подчёркивает масштаб мира.

## Ресурсы

### Духовные камни
- **Доход**: база max(1, floor(1.3^realmIndex)) + жалование ранга секты (1/2/4/8/15) +1 при медитации/Постижении Дао; затем процент артефактов и множитель Купца, +1 Золотой Эры. Мировой множитель применяется последним, с округлением вниз.
- **Источники**: события, доход, бой

#### Траты ресурсов

Камни тратятся на формации, вход в царства, защиту заточки и сюжетные покупки. Озарение стоит 10 + realmIndex × 3 + использований × 5 **эссенции** и сразу даёт `floor(10% текущего порога XP)` каждой незавершённой экипированной техники. `getInsightPurchaseInfo(count)` моделирует последовательные свитки: новый уровень меняет выдачу следующего, максимум исключает технику из последующих начислений. Пакет прекращается, когда все подходящие техники достигли максимума; оплачивается и учитывается только использованное число свитков. Покупка требует полной рассчитанной цены. Новые очереди XP не создаются; сохранённый оплаченный остаток старой очереди начисляется один раз при загрузке после восстановления техник и тиров.

### Награды достижений
Постоянная память достижений открывает контент. Множители кармы и Дао используют достижения текущей жизни (milestones); после перерождения их условия проверяются заново.

| Тир | Награда | Условие | Заметки |
|-----|---------|---------|---------|
| Бронзовые | +1% карма каждое | Только после первого перерождения | — |
| Серебряные | +1% карма каждое | Только после первого перерождения | — |
| Золотые | +1% карма каждое | Только после первого перерождения | — |
| Нефритовые | +2% скорость Дао каждое | — | — |
| Секретные | +5% скорость Дао каждое | — | — |

Максимальный бонус кармы от бронзовых/серебряных/золотых: **+54%** (10 бронзовых + 18 серебряных + 26 золотых текущей жизни).

Функция `getDaoSpeedMultiplier()` в `formulas.js` рассчитывает суммарный множитель скорости Дао:
```
daoSpeedMult = 1 + techBonus("daoSpeed") + jadeMilestones * 0.02
              + secretMilestones * 0.05 + artifactBonus("daoSpeed") * 0.01
```
Используется при тренировке и наградах экспедиций, заданий, приключений. Пожертвования дают вклад, не Дао; духовная пилюля даёт 8% текущего порога без этого множителя.

## Артефакты

Экипируемые предметы с бонусами. Дропаются из событий и тайных царств. 4 слота экипировки.

### Тиры артефактов (унифицированные названия)

Все системы (техники, артефакты, духовные корни, экспедиции) используют единую шкалу тиров:
**Смертный / Духовный / Мистический / Небесный / Священный / Божественный**

| Тир | Название | Множитель генерации | Базовый вес |
| --- | --- | --- | --- |
| common | Смертный | ×1 | 50 |
| uncommon | Духовный | ×1.5 | 25 |
| rare | Мистический | ×2 | 15 |
| epic | Небесный | ×3 | 7 |
| legendary | Священный | ×4 | 2.5 |
| divine | Божественный | ×6 | 0.5 |

Вес относится к обычному выбору до ограничений источника. Предел заточки всех тиров — +10; maxLevel метаданных тира его не задаёт.

### Слоты экипировки
| Слот | Основные бонусы | Редкий бонус (epic+, с года 3000) |
|------|----------------|-------------------------------|
| Оружие | +сила, +боевая мощь, +ци, +награда за опасность | — |
| Броня | +удержание ци, +долголетие, +дух, +эффект пилюль | снижение демонов |
| Аксессуар | +дух, +удача, +ци, +шанс прорыва, +карма | скорость времени |
| Сокровище | +ци, +XP техник, +доход камней, +множитель духа | скорость экспедиций или Дао |

### Генерация
- 1-2 эффекта из пула слота (2 для epic+)
- Значения берутся в верхней половине диапазона (min + (max−min)×0.5)..max, умножаются на тир и округляются до десятых
- Сумма экипировки проходит softcap(total, 50, 0.7), кроме strength/spirit/combatPower
- Редкий второй эффект с года 3000: броня demonReduction 15%, аксессуар timeSpeed 10%, сокровище expeditionSpeed или daoSpeed (по 15% на проверку кандидата)

### Нейминг (PoE-стиль)
**1 стат (common-rare):** `[Тир-Префикс] [База] [Суффикс стата]`
  - Пример: "Грозовой Меч Силы", "Нефритовая Роба Духа"

**2 стата (epic+):** `[Стат-Аффикс] [База] [Суффикс 2го стата]`
  - Аффикс определяется первым статом и тиром (epic/legendary/divine — разные слова)
  - Пример epic: "Разящий Клинок Мощи" (strength + combatPower)
  - Пример legendary: "Сокрушительная Секира Мощи" (strength + combatPower)
  - Пример divine: "Вознесённая Диадема Времени" (spirit + timeSpeed)

### Заточка (BDO-стиль)
- 10 уровней улучшения (+1..+10)
- Каждый уровень: ×1.2 к эффектам (экспоненциально: +5=×2.5, +10=×6.2)
- Базовый шанс: +1=90%, +5=45%, +7=25%, +10=8%; штраф тира 0/3/6/10/15/20 п.п., плюс Воля Дао, свитки и перк Кузнеца; предел 1%–100%
- При текущей заточке +0..+3 понижения нет; с текущей +4 провал гарантированно даёт −1 без защиты/перка Кузнеца. Первая попытка с риском — +4→+5
- Failstacks: +2% за каждый провал, накапливаются

### Слияние (Transcend, PRI-PEN)
- Два разных артефакта одного уровня слияния, любого слота/тира → следующий уровень
- PRI(×2) → DUO(×3) → TRI(×4) → TET(×6) → PEN(×8)
- Первое слияние требует оба на +10. Заточка сохраняется; дальнейшая заточка PRI+ запрещена

### Массовый разбор
- Кнопка "Разобрать..." открывает центрированный попап со списком тиров
- Каждый тир показан строкой с цветом тира: количество артефактов + суммарная пыль/эссенция
- Пропускаются экипированные и улучшенные (+1+) артефакты
- Enter подтверждает, Escape отменяет

Бонусы тела и секты усиливают базовую добычу и бонус слияния. Возврат заточки — отдельно 50% успешных вложений пыли и эссенции, без умножения бонусами разбора. Улучшить и разобрать предмет ради прибыли больше нельзя.

### При перерождении
- Все артефакты **сбрасываются**
- Кармическое улучшение "Память Артефактов" сохраняет до N экипированных артефактов (N = покупные и бесплатные уровни); приоритет: слияние, заточка, тир. Перки Воина отдельно переносят предметы из инвентаря

### Дао — механика

- **Дао бар** (0-100%) — второй бар помимо ци, появляется с реалма 3
- Каждая попытка с реалма 3, включая подуровни, требует ци ≥ qiNeeded и daoLevel ≥ (realmIndex − 3) × 4 + subLevel
- Прогресс повышает daoLevel автоматически; отдельные «100% Дао» в момент попытки не требуются
- Уровень Дао = число оплаченных порогов; он ограничивает покупку уровней любых открытых формаций текущей жизни
- **Кап Дао**: daoLevel ограничен requiredDao + 4 (нельзя перекачать больше чем на 4 уровня сверх текущего требования прорыва)
- Дебаффы уменьшаются с каждым уровнем Дао → на макс уровне превращаются в бонусы

### Прогрессивные требования Дао

```
Уровни 1-8 (линейная прогрессия):
  daoNeeded = 80 + daoLevel × 20

Уровни 9+ (квадратичный рост):
  daoNeeded = round_to_50((80 + daoLevel × 20) × (1 + (daoLevel - 8) × 0.25))
```

### Давление Дао (Дао Прессинг)

На высоких уровнях Дао при провале прорыва увеличивается **порог** срабатывания Внутреннего Демона (вместо добавления плоского % к шансу):

| Уровень Дао | Порог демона |
|-------------|-------------|
| 1-8 | 65% (базовый) |
| 9-16 | 70% (+5%) |
| 17-24 | 75% (+10%) |
| 25+ | 80% (+15%) |

Демон появляется если шанс прорыва < порога. Отображается в тултипе демона как "Давление Дао".

### Потеря Дао при провале прорыва

При провале прорыва (не демон) `daoProgress` теряется по той же формуле, что и ци:
```
daoLoss = daoProgress × (1 - totalReduction)
totalReduction = qiRetention (из техник + артефактов + секты + тела)
```
`qiRetention` защищает и ци, и Дао одновременно.

### Задания
3 слота заданий с независимым кулдауном: базовые 20 лет для любого ранга. В пяти реальных пулах используются 18 из 28 определений: 13 проверок существующих статов, 3 задания на годы медитации, 1 на прорыв и 1 на пожертвование пилюль. Десять ресурсных определений сохранены как резерв/legacy; сдача камней, пыли и эссенции не появляется в текущих пулах заданий. Отдельные кнопки пожертвования этих ресурсов продолжают работать.

После бонусов тела и Дао кулдаун составляет минимум 12 лет. Первый артефакт каждого соответствующего шаблона гарантирован за жизнь; повторная награда имеет шанс 5% и потолок rare. Отметка переживает смену секты и загрузку; полная сумка не тратит первую гарантию. Лимит инвентаря — 40.

`donate_pills_sect` получает награду автоматически при сдаче требуемого количества пилюль. Выплата за само пожертвование и награда задания сохраняются, повторное получение блокирует обычный кулдаун. Сдачи до появления нового задания в его счётчик не входят. Другие готовые задания остаются ручными.

Разблокировка по рангу: `minRank: 1` (Внутренний+), `minRank: 2` (Ядровой+), `minRank: 3` (Старейшина+), `minRank: 4` (Глава Секты).

**На максимальном ранге:** вклад конвертируется в камни и, при вкладе от 25, `floor(realm × 0.25)` пилюль. Свитки выдаются только явно указанными наградами задания.

**Множитель вклада при пожертвовании:** все 4 функции donate (камни, пилюли, пыль, эссенция) применяют `contributionMult` из перков тела (Сын Торговца: ×2, Гений Секты: ×1.5-2.5).

### При выходе из секты
- Техники секты **снимаются** (unequip) И **удаляются** из списка изученных
- Записи в глобальном массиве `TECHNIQUES` также очищаются
- Прогресс XP секта-техник теряется

### При перерождении
- Секта **сбрасывается** (ранг и вклад теряются)
- Можно выбрать ту же или другую секту

## Тайные Царства (Экспедиции)

Игрок отправляется в тайные царства на определённое время (в игровых годах). По завершении получает награды. На время похода медитация и её счётчик лет приостановлены; остальные тренировки продолжаются. Множители камней, эссенции, пыли и пилюль фиксируются при отправлении и сохраняются в сейве.

### Локации

| Локация | Мин. реалм | База, лет | Вход, камни | Базовые ресурсы и артефакт |
| --- | --- | --- | --- | --- |
| Лес Духовных Трав | 0 | 25 | 10 | 8–20 камней, 1–3 пилюль; 15%, common..common |
| Пещера Древнего Зверя | 0 | 30 | 15 | 10–30 камней, 1–3 пилюль; 30%, common..uncommon |
| Руины Забытой Секты | 0 | 35 | 30 | 20–60 камней, 2–5 пилюль; 50%, common..uncommon |
| Небесный Аукцион | 3 | 15 | 100 | 2–6 пилюль; 100%, common..uncommon |
| Бездна Демонов | 6 | 120 | 50 | 40–120 камней, 3–8 пилюль; 65%, uncommon..rare |
| Дворец Павшего Бессмертного | 7 | 200 | 100 | 80–250 камней, 5–12 пилюль; 80%, rare..rare |
| Тайное Царство Секты | 7 | 80 | 0 | 50–150 камней, 4–10 пилюль; 70%, common..uncommon |

Исходные диапазоны до множителей и вычета входа. Тайное Царство Секты требует ранг Глава Секты (индекс 4).

### Формулы наград
```
ascend = [1, 2, 2.5][ascendTier]
bonus = min(3, max(0, era.rewardWeight - 1) + max(0, world.expeditionReward - 1) + dangerBonus)
total = (1 + bonus) * ascend
luckMult = 1 + 0.5 * (1 - exp(-sqrt(totalLuck) * 0.16))
rewardRealm = min(playerRealm, location.minRealm + 2 * ascendTier, 10)
stoneReward = floor(base * stoneTotal * (1 + rewardRealm * 0.3) * luckMult)
essenceReward = dustReward = floor(base * total * luckMult)
pillReward = floor(base * total)
artifactChance = baseChance * (1 + 0.5 * totalLuck / (totalLuck + 50))
```

Отсутствующие мировые множители равны 1. `stoneTotal` включает также бонус мирового дохода камней в ту же ограниченную сумму. Бонус опасности действует только в опасных локациях. Боевая мощь определяет безопасность, но не увеличивает добычу. Шанс второго артефакта — только остаток `artifactChance − 1` сверх 100%. Все артефакты, включая дополнительный от тела, соблюдают минимальный и максимальный тир локации. UI использует те же helpers.

### Скорость
- Длительность = `max(10, floor(baseDuration / (1 + speedBonus)))`.
- Формация "Врата Тайного Царства" даёт +6% скорости за уровень; бонусы тела и артефактов складываются с ним.
- Одна экспедиция одновременно

### Вознесённые приключения (ascend_)
Финальный шаг приключений с id, начинающимся на "ascend_" или "ascend2_", автоматически получает длительность 20 лет, если не задана другая длительность.

### Вознесение локаций (Location Ascension)

Испытание тира 1 открывается после 10 общих походов в локацию за текущую жизнь; такие приключения есть у шести царств, кроме Тайного Царства Секты. Тир 2 существует только у леса, пещеры и руин: нужны 20 общих походов этой жизни и выполненное первое вознесение, обычно ещё десять походов после первых десяти. Сюжетное первое вознесение счётчик не обнуляет. Цена списывается при принятии, вознесение даёт успешная финальная ветка; интерфейс показывает только существующие испытания.

| Испытание | Тир | Камни | Эссенция | Пыль |
| --- | --- | --- | --- | --- |
| Сердце Древнего Леса | 1 | 300 | 50 | 50 |
| Логово Праотца Зверей | 1 | 500 | 80 | 80 |
| Запретный Архив Секты | 1 | 800 | 120 | 100 |
| Небесный Чёрный Рынок | 1 | 1500 | 80 | 80 |
| Сердце Бездны | 1 | 2000 | 200 | 150 |
| Тронный Зал Бессмертного | 1 | 3000 | 300 | 250 |
| Корень Мира | 2 | 600 | 100 | 100 |
| Охотничьи Угодья Праотца | 2 | 1000 | 150 | 150 |
| Тайна Совета Девяти | 2 | 1500 | 200 | 200 |

Тир 1 даёт ×2 ресурсные награды; тир 2 — ×2.5 и гарантированный свиток Дао. Опасность задаётся значением локации (лес 100, пещера 120, руины 140, бездна 180, дворец 300), а не прибавкой +100. Второе вознесение использует ту же опасность, что первое; эпоха и мировой модификатор применяются отдельно. Качество артефактов ограничено диапазоном локации. Тиры, счётчики и выполненные приключения сбрасываются при перерождении; постоянный маркер прохождения хранит историю, не тир следующей жизни.

## Приключения

Параллельная система квестов с выбором. Не прерывает основной геймплей.

### Поток
1. Случайное событие генерирует **слух** → появляется в табе "Приключения"
2. Игрок **принимает** приключение (макс 1 активное, макс 5 слухов)
3. Каждый шаг: текст + **2-3 варианта** (разная длительность/стоимость/проверка стата)
4. Провал проверки не блокирует — даёт ослабленный результат или штраф
5. Финальный шаг определяет награды на основе накопленных флагов
6. Непринятые обычные слухи истекают через 100 лет; слухи испытаний вознесения не истекают

Награда на шаге с `nextStep` является промежуточной: выдаётся один раз и не завершает приключение. Отложенная финальная ветка сохраняется по индексу шага/выбора; её эффект применяется при завершении с накопленными флагами. В обработчиках данных используется сигнатура `(game, flags, results)`. Стоимость и проверка выбора могут быть объектом или функцией от флагов; эффект разрешается до списания, а выбор без допустимого исхода не расходует ресурсы.

### Проверки поздних испытаний

`challengeRealm` задан самим содержимым шести поздних приключений и испытания Дворца Бессмертного. `getAdventureCheck(adv, choice, flags)` вычисляет `ceil(исходный порог × коэффициент)` и одинаково используется логикой, карточкой выбора и сведениями о боссе. Требование не растёт от текущих статов или реалма героя; ранние, средние и прочие испытания локаций сохраняют прежние проверки.

| Ступень содержания | Сила | Дух | Удача | Боевая мощь |
| --- | --- | --- | --- | --- |
| 7 | ×3 | ×3.5 | ×2 | ×4 |
| 8 | ×3 | ×4 | ×2.4 | ×5 |
| 9 | ×3.2 | ×4.4 | ×2.8 | ×6 |

Примеры: очищение в Испытании Небесной Кары требует дух 133; бой в Бездне Кровавой Луны — силу 105; испытание и выход Осколка Небесного Дворца — мощь 330 и 300. Это фиксированные цели подготовки, а не подстройка против сильного персонажа.

### Последствия подготовки и семян

- Пожиратель Корней: успешная приманка снижает удачу захвата с 8 до 4 и оставляет полную цену живой добычи 25–45 камней; провал отнимает 5% запаса ци для прорыва и не облегчает финал. Затопление занимает 10 лет, снижает силу убийства 9→6 и удачу захвата 8→6, но снижает цену продажи до 18–30.
- Зал Гробницы: успешная проверка духа даёт +25% эссенции; силовой проход даёт +50% пыли, но вдвое снижает шанс техники, включая неудачный силовой проход без дополнительной пыли. Успешная удача добавляет 25 п.п. к шансу артефакта (предел 100%) и повышает его минимальный тир; её провал вдвое снижает шанс артефакта. Изменения применяются к выбранному наследию, включая флаги старых сохранений.
- Небесный Чёрный Рынок: платные 200 камней открывают артефакт не ниже rare вместо uncommon; путь по связям сохраняет бесплатный вход и больше пыли. В финале выдаётся один артефакт.
- `ancient_tree_seed` или `dao_tree_seed` дают один множитель ×1.30 к итоговой карме жизни после бонусов тела, формаций, секты, достижений и естественной смерти, с округлением вниз. Два семени не складываются; до реалма 3 карма остаётся нулевой. Флаги сбрасываются с новой жизнью, повторное открытие перерождения не начисляет награду снова.

## Взаимосвязи систем

```
Корень → ци; совпадение элемента → XP техники ×1.50, эффект ×1.25
Дух → медитация (+6% до софткапа) и XP техник (+2%/ед.)
Сила → медитация (+3% до софткапа) и база боевой мощи
Удача → шанс прорыва через sqrt; вес и добыча наград с пределом +50%
Техники в экипировке → пассивный XP → уровни → эффекты с ослаблением
Секта → тренировка Дао → daoLevel → допуск каждой попытки прорыва
Задания/пожертвования → вклад → ранг → доступ заданий и жалование
Камни → формации на жизнь, входы, защита заточки, сюжетные покупки
Эссенция/пыль → заточка, слияние, вознесения; эссенция → немедленный XP Озарения
Экспедиции → ресурсы и экипировка; медитация в походе приостановлена
Приключения → общий таймер слухов → выбор/ожидание шагов → награды
Перерождение → карма и постоянные открытия → новая жизнь с телом
Формации: открытие сохраняется, уровни и выбор сбрасываются
Артефакты: перенос через Память Артефактов и перк Воина
```

### Петля прогрессии

Медитация заполняет ци, подходящая секте тренировка повышает Дао; вместе они открывают попытку прорыва. Экипированные техники усиливают темп, экспедиции снабжают ресурсами для улучшений. Перерождение сохраняет карму, покупки, достижения и доступ к формациям, затем применяет стартовые бонусы тела.

## Таймеры

| Интервал | Функция | Что происходит |
|----------|---------|----------------|
| 200 мс | `tick()` | Ци, активный/пассивный XP статов и техник (по 1/5 скорости); страховочное начисление остатка legacy-Озарения |
| 5 сек | `passYear()` | +1 год, доход камней, смена эпох, мировые события, проверка смерти |
| 15 сек | `triggerEvent()` | Случайное событие (цепочки → манхва → обычные, 50% шанс пропуска) |
| 30 сек | `autoSave` | Сохранение в localStorage (+ при beforeunload и паузе) |

Три игровых интервала масштабируются getSpeedMultiplier() = 1 + (timeFlow + freeLevels) × 0.25 + techTimeSpeed + artifactTimeSpeed × 0.01 и debugSpeed. Автосохранение не ускоряется. refreshTimers() пересчитывает интервалы при смене эффектов времени, включая снятие, заточку и слияние артефактов.

Debug-режим: множитель debugSpeed ускоряет три игровых таймера пропорционально.

### Таймер смерти
Опциональный переключатель в настройках (`game._showDeathTimer`). Показывает оставшееся время до maxAge в формате часы:минуты:секунды с учётом текущей скорости игры.

### Хроники (лог событий)

- Все игровые события записываются в лог ("Хроники") в правой панели
- Каждая запись содержит временную метку: `[X г.] текст`
- **Переключатель времени** (кнопка "Мир"/"Возраст" в заголовке):
  - **Мир** (по умолчанию): показывает мировой год (`game.years`)
  - **Возраст**: показывает возраст персонажа (`game.characterAge()`)
- Каждая запись лога сохраняет оба значения в `data-worldYear` и `data-charAge`
- Максимум 150 записей; в сохранение попадают последние 50
- **Не логируются**: апгрейды формаций, использование пилюль, переключение активностей, разбор артефактов (одиночный и массовый), повышение уровня статов, повышение уровня техник (кроме максимального), выполнение заданий секты (награда Дао)
- При достижении техникой максимального уровня выводится "достигла максимума! Вознесение доступно." вместо номера уровня
- Достижения логируются только при **первом** получении (не при повторном достижении в новой жизни)

## Перерождение (Prestige)

Система перерождения — NG+ механика, вдохновлённая Realm Grinder и Progress Knight Quest. При смерти или добровольно (реалм 3+ и минимальный возраст) игрок перерождается, сохраняя постоянные бонусы.

### Карма (престиж-валюта)

Начисляется за прогресс текущей жизни:
```
karma = realmIndex + floor(characterAge / 500)
      + floor(techniques.length * 0.3) + floor(validMilestones.length * 0.2)
      + floor(breakthroughKarma) + sectRankIndex + contributionKarma
contributionKarma = floor(min(2 * sectRankIndex,
    8 * sqrt(clamp(sect.contribution / headThreshold, 0, 1))))
karma *= (1 + bodyKarmaBonus + formationKarmaBonus + artifactKarmaBonus)
karma *= sectKarmaMultiplier
karma *= 1 + milestoneKarmaBonus // после первого перерождения
karma *= 1.5  // только при естественной смерти — "Мудрость Полной Жизни"
karma = floor(karma * 1.30) // при любом из двух семян, один раз после остальных множителей
```

Ниже реалма 3 карма равна 0. За прорывы в реалмах 3–8 начисляется 0.5, начиная с реалма 9 — `5 + (realm − 9) × 3`; считаются завершённые реалмы и текущие подуровни. `headThreshold` учитывает сложность секты. Каждая стадия умножения округляется вниз; максимум кармы вклада — +8 у Главы, накопление вклада за недоступным по реалму рангом его не обходит.

**Масштабирование стоимости улучшений:**
```
upgradeCost(level) = costs[level] или ceil(baseCost * (1 + level * 0.5))
```
Линейная схема добавляет 50% базы за покупной уровень; массив costs задаёт отдельные цены. Скидка эпохи применяется после выбора цены.

Общая накопленная карма для пассивной ци и Небесного Барьера = `prestige.karma + prestige.karmaSpent`. Второе поле — фактически оплаченные цены улучшений и вознесений тел, включая скидки. Покупка не увеличивает эту сумму. Расходы не восстанавливаются из номинальной цены уже купленных уровней. Подробная проверка правил открытия, пропусков тел и звёзд — в [prestige_review.md](prestige_review.md).

### Что сохраняется между жизнями
- **Карма** — накапливается (не сбрасывается)
- **Расходы кармы** — журнал фактически оплаченной суммы `karmaSpent`
- **Достижения** — перманентны (permanentMilestones)
- **Кармические улучшения** — постоянные бонусы
- **Счётчик перерождений** — totalRebirths
- **Вознесения тел** — bodyAscensions
- **Доступ к формациям и память путей Дао** — unlockedFormations и daoLevels; выбор/уровни формаций на жизнь сбрасываются
- **Мировое время** — мир продолжает жить (worldAge)

### Что сбрасывается
- Ци, реалм, подуровень
- Статы (сила, дух, удача) → базовые + бонусы от тела и кармы
- Ресурсы (камни, пилюли) → бонусы от тела и кармы
- Техники → только стартовые от тела
- Флаги событий и цепочек
- Секта (ранг и вклад теряются)
- Экспедиция
- Артефакты (кроме сохранённых "Памятью Артефактов" и перенесённых Воином)
- Пыль/эссенция (кроме переноса Алхимика)
- Failstacks (кроме переноса Кузнеца)

После переноса `prestige.lastLifeResources` хранит неперенесённый остаток пыли/эссенции для тайников. Полный перенос не даёт повторно получить процент тех же материалов из событий новой жизни; сохраняются обычные тайники камней и пилюль.

### Межжизненные синергии (Cross-Life Loops)

Тела создают стратегические циклы между перерождениями:

```
Воин (экспедиции → артефакты)
  ↓ передаёт артефакты (★1+)
Алхимик (разбирает → пыль/эссенция)
  ↓ переносит пыль/эссенцию
Кузнец (затачивает, сохраняет failstacks)
  ↓ затачивает + создаёт PEN артефакты
Воин (экипирует → ещё экспедиции)
  ↓ ... цикл
```

Подсказки совпадают с фактическими условиями; legacy-id достижений сохраняются для совместимости сейвов.

### Добровольное перерождение — Рассеивание Культивации (散功)

Доступно с реалма 3 при возрасте ≥ 150 − 10 × (earlyRebirth + freeLevels). Без улучшений — 150 лет; при десяти покупных уровнях — 50; с двумя бесплатными уровнями Архата — 30. Даёт стандартную карму без бонуса естественной смерти.

### Мудрость Полной Жизни

При **естественной смерти** карма увеличивается на **+50%**. Дилемма:
- Переродиться рано = больше циклов, быстрее тела/улучшения
- Прожить до конца = больше кармы за жизнь, но медленнее

### Поток перерождения
```
Смерть (естественная, +50% кармы) или Рассеивание Культивации (реалм 3+ и минимальный возраст)
  → Расчёт кармы (реалм + возраст + техники + достижения + прорывы + секта)
  → Применение множителей (тело, секта, естественная смерть)
  → Модалка перерождения:
      ├── Однократное начисление кармы и сохранение pendingRebirth
      ├── Разбивка заработанной кармы
      ├── Кармический магазин (улучшения с масштабируемой стоимостью)
      ├── Вознесение тел (покупка за карму)
      └── Выбор тела перерождения (сгруппированы по тирам)
  → Выполнение перерождения:
      ├── Достижения мержатся в permanentMilestones
      ├── totalRebirths++
      ├── Полный сброс (reset)
      ├── Перенос ресурсов (Алхимик: пыль/эссенция, Воин: артефакты, Кузнец: failstacks)
      ├── Применение бонусов тела (статы, ресурсы, техники, перки)
      ├── Применение вознесённых перков (if ascLevel > 0)
      ├── Применение кармических улучшений (+ бесплатные уровни Архата)
      ├── Уровни Древнего при последующем выборе формаций
      └── Выбор нового духовного корня (с мин. тиром тела/вознесения)
  → Начало новой жизни
```

Загрузка или импорт незавершённого перерождения открывает сохранённый выбор без запуска времени и повторного начисления кармы. Покупки и выбранное тело сохраняются. Новое Озарение не создаёт очереди; поля legacy-остатка очищаются при переходе в новую жизнь.

### Взаимосвязи с другими системами
```
Достижения + Перерождения ──→ Разблокировка тел (тиры 0-6)

Тела ────────────┬──→ Стартовые статы/ресурсы/техники
                 ├──→ Уникальные перки (подключены к формулам)
                 ├──→ Мин. тир духовного корня
                 ├──→ Стартовый реалм
                 └──→ Множитель кармы

Вознесение тел ──┬──→ Усиленные перки (3 уровня)
                 └──→ Межжизненные синергии (передача ресурсов)

Карма ───────────┬──→ Кармические улучшения (масштабируемая стоимость)
                 ├──→ Вознесение тел
                 └──→ Небесный Барьер (гейт для реалмов 10+)
```
