# Баланс: Путь Культиватора

## Статы (Сила / Дух / Удача)

### XP до уровня
```
statXpNeeded = floor(baseCost * level * pow(1.05, level))
baseCost: сила/дух = 5, удача = 8
```

### XP за тик (1 сек)
```
statXpPerTick = 1.0 * pow(level, 0.7) * (1 + realmIndex * 0.15) * karmaMult
```
- `level^0.7`: level 1→1.0, level 5→3.1, level 10→5.0, level 50→18.8
- `realmIndex * 0.15`: +15% за реалм
- `karmaMult`: +5% за уровень "Совершенствование" (+5% множитель духа)
- Бонусы формаций/секты/артефактов/техник НЕ влияют на скорость XP статов (statXpSpeed больше не ускоряет прокачку, а умножает дух)
- Все 3 стата качаются пассивно на 15% (PASSIVE_STAT_RATE = 0.15)
- Активный стат — 100%

**Время на уровень (без бонусов, сила/дух):**
| Level | XP нужно | XP/тик (r0) | Секунд | XP/тик (r5) | Секунд |
|-------|----------|-------------|--------|-------------|--------|
| 1     | 33       | 3.0         | 11с    | 5.3         | 6с     |
| 5     | 264      | 7.8         | 34с    | 13.7        | 19с    |
| 10    | 932      | 12.0        | 78с    | 21.0        | 44с    |
| 20    | 5,788    | 18.9        | 5мин   | 33.1        | 3мин   |

### Эффекты статов
- **Сила**: +3% ци за уровень (softcap после 100: sqrt scaling), боевая мощь
- **Дух**: +6% ци за уровень (softcap после 100: sqrt scaling), +2% скорость XP техник за уровень
- **Удача**: sqrt(luck)×8% к наградам из экспедиций, бонус шанса прорыва (sqrt scaling)

### Софт-кап статов (v13)
```
softcap(x, threshold, power = 0.5):
  x <= threshold: x
  x > threshold: threshold + (x - threshold)^power
```
- spirit/strength: softcap(stat, 100, 0.5) — линейно до 100, sqrt после
- statXpSpeed (совершенствование): softcap(total, 3.0, 0.5) — линейно до +300%, sqrt после
- Артефакт %-эффекты: softcap(total, 50, 0.7) — линейно до +50%, затем pow 0.7
- Артефакт tierMult (v13): common=1, uncommon=1.5, rare=2, epic=3, legendary=4, divine=6
- Однотипные техники: diminishing weights [1.0, 0.6, 0.4, 0.25, 0.15]
- Экспедиции: danger+power аддитивны, era мультипликативна; luck = sqrt(luck)×0.08; realm кап = 10
- События ци: eventQiBonus() — кап = 10 минут медитации (qiPerSec×600) на realm 6+
- Эры rewardWeight: max 2.5 (было 5.0); мировые события: max 2.0 (было 4.0)

### Пилюли (v13 — тировая система)
```
Тир 1 (Пилюля Ци):      500 ци      — базовая
Тир 2 (Очищенная):     5,000 ци      — рефайн 5:1 (4:1 у Алхимика) + 5 пыли
Тир 3 (Духовная):     50,000 ци      — рефайн + 20 пыли | +8% дао, +5% прорыв (кап +25%) | Алхимик ★1
Тир 4 (Небесная):    500,000 ци      — рефайн + 100 пыли | +1 перм. стат (наименьший) | Алхимик ★2
```
- Фиксированные значения, не % от qiNeeded — естественный diminishing через рост qiNeeded
- Рефайн стоит пыль артефактов (sink)
- Тир 2→3 и 3→4 гейтнуты за вознесение тела Алхимика
- Алхимик ★3 (Архиалхимик): авто-рефайн каждый год
- Алхимик базовый: рефайн 4:1 вместо 5:1
- `_pillBreakthroughBonus` стакается до +25% (5 духовных пилюль), расходуется при попытке прорыва

## Ци

### Ци за секунду (только при активности "Медитация")
```
base = 5 + realmIndex * 3
qiPerSec = max(1, floor(base * spiritMult * strengthMult * qiMult * techQiMult * formationMult * artifactMult * sectMult * treasuryMult * elemMult))
```
Игра полностью idle — кнопка клика удалена, все бонусы ци унифицированы под ключ `qi`.

## Прорыв

### Шанс прорыва
```
Realm < 3: 100% (гарантирован)
Realm 3+:
  mortalSteps = min(realmIndex - 3, 7)
  immortalSteps = max(0, realmIndex - 10)
  realmPenalty = mortalSteps * 0.10 + immortalSteps * 0.15
  subLevelPenalty = (subLevel - 1) * 0.025  // -2.5% за подуровень (sub 1=0%, sub 4=-7.5%)
  baseChance = 0.70 - realmPenalty - subLevelPenalty
  chance = baseChance + sqrt(luck)*0.006
           + techBonus + artifactBonus + sectBonus + formationBonus + bodyBonus + dreamBonus
  chance = max(0.01, min(chance, 0.95))
```

**Источники бонусов:**
- Удача: `sqrt(totalLuck) * 0.006` (totalLuck = база + артефакт + формация)
- Техники: `getTechBonus("breakthroughBonus")` (breakthroughBonus эффект × уровень × тир-множитель)
- Артефакты: `getArtifactBonus("breakthroughBonus") * 0.01`
- Секта: `getSectBonus("breakthroughBonus")` (интерполяция Дао 0-5, Нефрит: 2-6%)
- Формация: `getFormationBonus("breakthroughBonus")` (Алтарь Прорыва: +0.4% за уровень)
- Тело: bodyPerks.breakthroughBonus
- Пророческий сон: +5% (одноразовый, из события)

**НЕ влияют на прорыв:** дух, сила, ранг секты.

| Realm | Base | Первая жизнь (без бонусов) | С техниками+формациями |
|-------|------|---------------------------|----------------------|
| 3 | 70% | ~72% | ~95% (кап) |
| 5 | 50% | ~52% | ~82% |
| 7 | 30% | ~32% | ~62% |
| 8 | 20% | ~22% | ~52% |
| 9 | 10% | ~12% | ~42% |
| 10 | -5% | ~1% (кап) | ~27% |
| 11 | -20% | ~1% (кап) | ~12% |

Хардкапов нет — единый коридор 1%-95%. Base уходит в минус на бессмертных реалмах, компенсируется техниками/формациями/секта/артефакты. Дух и сила не дают бонуса к прорыву.

### Внутренний Демон (при провале, если шанс прорыва < порога)

Порог зависит от Давления Дао: базовый 65%, повышается до 70%/75%/80% на высоких уровнях Дао.

```
demonThreshold = 0.65 + daoPressureThresholdBonus
demonChance = min(0.80, (demonThreshold - breakthroughChance) / demonThreshold)
effectiveDemonChance = max(0, demonChance - bodyReduction - formationReduction - artifactReduction)
```

**Давление Дао (daoPressure):** увеличивает порог срабатывания демона (вместо добавления плоского %):
- daoLevel 1-8: порог 65% (+0%)
- daoLevel 9-16: порог 70% (+5%)
- daoLevel 17-24: порог 75% (+10%)
- daoLevel 25+: порог 80% (+15%)

Отображается в тултипе как "Давление Дао".

При срабатывании — потеря реалмов (1-4), статов, Дао (реалмы-1).

| Realm | Шанс прорыва (с бонусами) | Демон? | Потеря реалмов |
|-------|--------------------------|--------|----------------|
| 7 | ~62% | Да (5%) | -2 |
| 8 | ~52% | Да (20%) | -3 |
| 9 | ~42% | Да (35%) | -3 |
| 10 | ~27% | Да (58%) | -4 |

Демон обнуляет ци, ставит subLevel=1, жрёт статы и Дао (daoLevel -= потерянные реалмы - 1), снимает лишние техники из экипированных. Страховка защищает от всего.

### Провал прорыва
При провале (не демон):
- **Ци**: теряет baseLoss × (1 - totalReduction)
- **Дао прогресс**: теряет baseLoss × (1 - totalReduction) — та же формула, что и ци
- **Статы** (realm 7+): -1 сила, -1 дух (realm 10+: -2). Удержание может защитить (шанс)
- **Удержание ци (qiRetention)**: защищает и ци, и дао. Сумма от техник + артефактов + секты + тела (макс 95%)

Удержание ци — критически важный стат на высоких реалмах. Без него каждый провал = начинай сначала.

## Удержание Ци (qiRetention)

Снижает потери при провале прорыва (ци и статы).
```
qiRetention = min(0.60, techBonus + artifactBonus*0.01 + sectBonus)
```

Источники:
- Техника **Железное Тело**: +2% за уровень
- Техника **Небесный Щит**: +0.4% за уровень (нерфнуто с +0.625%)
- Техника **Лунное Очищение** (секта): +0.8% за уровень (нерфнуто с +3%, макс 5 уровней вместо 10)
- Артефакты (слот брони): переменное значение
- Секта **Лунного Озера**: +15% (масштабируется с рангом и аффинити)

## Долголетие (lifespan)

Увеличивает максимальный возраст.
```
maxAge = floor(baseMaxAge * (1 + lifespanBonus))
lifespanBonus = techBonus("lifespan") + artifactBonus("lifespan") * 0.01
```

Источники:
- Техника **Деревянное Обновление**: +2% за уровень
- Артефакты: переменное значение

## Элементальная система

### Элементы
Огонь, Вода, Дерево, Земля, Ветер, Гром, Пустота (🕳️, #8844aa)

7-й элемент "Пустота" добавлен, но никакие техники пока его не используют. Культ Бездны имеет element: null (не void) — без аффинити бонуса/штрафа.

### Элементальный резонанс (техники)
+12% к ци за каждую экипированную технику, чей элемент совпадает с элементом корня.

### Аффинити секты
- Элемент корня совпадает с элементом секты: **×1.5** ко всем бонусам секты
- Не совпадает: **×0.75** ко всем бонусам секты
- Секта без элемента (Культ Бездны): **×1** (нет штрафа/бонуса)

### Аффинити техник
- Элемент корня совпадает с элементом техники: **×1.50** к скорости XP техники
- Эффекты техники при отображении также умножаются на ×1.50

- Записи техник секты удаляются из глобального массива `TECHNIQUES`
- Весь прогресс XP секта-техник теряется

## Артефакты

### Тиры (унифицированные названия)

Все системы (техники, артефакты, корни, экспедиции) используют единую шкалу:
**Смертный / Духовный / Мистический / Небесный / Священный / Божественный**

| Тир       | Название      | Множитель | Макс уровень | Вес дропа |
|-----------|---------------|-----------|-------------|-----------|
| common    | Смертный      | ×1        | 3           | 50        |
| uncommon  | Духовный      | ×1.5      | 5           | 25        |
| rare      | Мистический   | ×2.5      | 8           | 15        |
| epic      | Небесный      | ×4        | 10          | 7         |
| legendary | Священный     | ×7        | 12          | 2.5       |
| divine    | Божественный  | ×12       | 15          | 0.5       |

Epic+ артефакты имеют 2 эффекта вместо 1.

### Эффекты по слотам
Базовые значения (min–max) умножаются на множитель тира.

| Слот | Эффект | Диапазон | Как применяется |
|------|--------|----------|-----------------|
| **Оружие** | Сила (strength) | 2–5 | +flat к боевой мощи |
| | Боевая мощь (combatPower) | 1–4 | +% боевой мощи |
| | Ци (qi) | 1–3 | +% ци/сек |
| **Броня** | Удержание ци (qiRetention) | 2–5 | +% снижение потерь при провале прорыва |
| | Долголетие (lifespan) | 1–3 | +% макс. возраст |
| | Дух (spirit) | 1–3 | +flat к духу (×0.05 = +% ци/сек) |
| **Аксессуар** | Дух (spirit) | 2–5 | +flat к духу |
| | Удача (luck) | 1–4 | +flat удача (шанс прорыва, награды) |
| | Ци (qi) | 1–3 | +% ци/сек |
| | Шанс прорыва (breakthroughBonus) | 1–2 | +% шанс прорыва |
| **Сокровище** | Ци (qi) | 2–5 | +% ци/сек |
| | Уклонение (dodgeChance) | 1–3 | +% шанс избежать danger-событий |
| | XP техник (techXpSpeed) | 2–5 | +% скорость XP техник |
| | Доход камней (stoneIncome) | 1–3 | +% доход камней/год |

Итоговый эффект = `base × tierMult × enhanceMult × transcendMult`.
Пример: divine сокровище (qi 4.0 × 12) = 48% ци → при PEN +10 (×16) = **+768% ци**.

### Инвентарь
Макс. 40 артефактов (увеличен для поддержки системы слияния).

### Заточка (Enhancement, +0..+10)

**Прогрессивный множитель эффектов:**
```
enhanceMult = 1 + enhance * (enhance + 5) / 50
```

| +5      | ×2.00     | +28%    |

| +8      | ×3.08     | +40%    |

**Таблица заточки:**
| Уровень | Эссенция | Пыль | Шанс | Защита (камни) |
|---------|---------|------|------|----------------|
| → +1    | 10      | 10   | 90%  | 15             |

**Даунгрейд при провале:**
- +1..+3: нет даунгрейда
- +4..+6: 50% шанс -1 уровень
- +7..+10: 100% -1 уровень

Духовные камни (защита) предотвращают даунгрейд. Доступны на ВСЕХ уровнях.

**Воля Дао (failstacks):** +2% к шансу заточки за каждый провал подряд. Сбрасывается при успехе.

**Свитки Воли Дао:** Расходный предмет, каждый = +2% к шансу заточки. Макс 10 свитков применено одновременно (+20%). Бонус свитков **не пропадает при провале**, сбрасывается только при **успешной** заточке. Обычная Воля Дао (от провалов, +2% за провал) считается отдельно. Итого шанс = base + failstacks×2% + scrolls×2%. Количество свитков в инвентаре не ограничено. Источники:
- Ветеранские задания секты (ранг Старейшина+, `minRank: 3`)
- Экспедиции: Бездна Демонов (15%), Дворец Бессмертного (25%), Тайное Царство Секты (20%)
- Сбрасываются при перерождении.

### Слияние (Transcend, PRI→PEN)

Два артефакта +10 одного слота и одного уровня слияния → следующий уровень.
Заточка сбрасывается до +0 при слиянии.

```
totalMult = enhanceMult × transcendMult
PEN +10 = ×4.0 × ×4.0 = ×16.0 к базовым эффектам
```

| 3       | TRI      | ×2.2      | 400     | 200  |
| 4       | TET      | ×3.0      | 1000    | 500  |
| 5       | PEN      | ×4.0      | 2500    | 1200 |

Для PEN нужно 2⁵ = 32 артефакта +10 одного слота (экспоненциальный sink).

```
eventMs = floor(15000 / speedMult)            // 15000мс → 7500мс на макс
```
