# План: Пути Дао + Формации Сект (Фаза 4)

## Концепция

На Золотом Ядре (реалм 3) культиватор формирует Сердце Дао — выбирает путь через секту. Дао = второй бар прогрессии (помимо ци), необходимый для прорыва реалма. Каждая секта даёт свой Путь Дао и 2 уникальные формации.

| Секта | Путь Дао | 中文 | Дао бонус (ур.0) | Дао бонус (ур.5) | Дебафф (ур.0) | Дебафф (ур.5) |
|-------|----------|------|------------------|------------------|---------------|---------------|
| Нефрит | Путь Воды | 水道 | +5% ци, +5% прорыв | +15% ци, +15% прорыв | — | — |
| Пламя | Путь Меча | 剑道 | +10% боевая мощь | +25% боевая мощь, +10% пилюли | −10% пилюли | → +10% |
| Озеро | Путь Пламени | 火道 | +10% пилюли | +25% пилюли, +15% разбор артефактов | −10% боевая мощь | → 0% |

## 2. Дао — механика второго бара

### Когда появляется
- Реалм 3+ (Золотое Ядро). До реалма 3 — нет Дао, прорывы только по ци.
- Нужно вступить в секту чтобы получить Путь Дао.
- Без секты = без Дао = застрял на реалме 3 навсегда.

### Бар постижения (0-100%)
- Для **прорыва реалма** (3+): ци ≥ 100% **И** дао ≥ 100%
- Для прорыва **подуровня**: только ци (как раньше)
- После прорыва реалма: бар дао сбрасывается, уровень Дао +1
- Требования к заполнению бара растут с каждым уровнем

### Состояние
```
game.daoProgress = 0.0      // текущий прогресс 0-100 (бар)
game.daoLevel = 0           // сколько раз заполнил бар (= уровень Дао)
// При перерождении:
game.daoProgress = 0        // сбрасывается
game.daoLevel = 0           // сбрасывается
// Перманентно:
prestige.daoLevels = { jade_purity: 3, crimson_flame: 1 }  // макс достигнутый уровень по каждой секте
```

### Источники Дао (что качает бар)

| Источник | Дао за единицу | Заметки |
|----------|---------------|---------|
| **Тренировка (активность)** | ~0.5-1% в год | ЗАВИСИТ ОТ СЕКТЫ — см. таблицу ниже |
| **Экспедиции** | +15-30% за завершение | ×2 если секта совпадает с локацией |
| **Тайное Царство Секты** | +40-50% | Нужен ранг Глава Секты |
| **Задания секты** | +3-8% за выполнение | Только после открытия Дао (реалм 3+) |
| **Приключения** | +5-15% за завершение | Зависит от сложности |
| **Свитки Озарения** | +10-15% разово | Покупка за камни |
| **События** | +2-5% случайно | Редкие события постижения |

### Какая активность качает Дао (по секте)

| Секта | Активность → Дао | Лорная логика |
|-------|------------------|---------------|
| **Нефрит** (Вода) | Постижение Дао (дух) | Гармония через медитацию и созерцание |
| **Пламя** (Меч) | Закалка Тела (сила) | Дао познаётся через бой и тренировку |
| **Озеро** (Пламень) | Постижение Дао (дух) | Знание и мудрость — путь алхимика |
| **Бездна** (Убийство) | Закалка Тела (сила) ИЛИ Испытание Судьбы (удача) | Риск и сила — два столпа тёмного пути |
| **Скрытая** (Свобода) | Любая из трёх (×0.5 скорость) | Свобода = любой путь, но без специализации |

Медитация (ци) НИКОГДА не качает Дао. Нельзя просто сидеть и ждать.

### Что НЕ даёт Дао
- Медитация (только ци)
- Пилюли (только ци)
- Пассивное ожидание

### Привязка экспедиций к сектам (×2 Дао)

| Экспедиция | Секта (×2) | Лорная связь |
|------------|-----------|--------------|
| Лес Духовных Трав | Нефрит (Вода) | Природа, гармония, чистота ци |
| Пещера Древнего Зверя | Пламя (Меч) | Бой, закалка, хищники |
| Руины Забытой Секты | Озеро (Пламень) | Древние знания, свитки, алхимия |
| Бездна Демонов | Бездна (Убийство) | Демоны, тьма, поглощение |
| Небесный Аукцион | нейтральная | Торговля, всем полезно |
| Дворец Бессмертного | нейтральная | Высший уровень, всем полезно |
| Тайное Царство Секты | текущая секта | Большой флэт бонус, нужен Глава Секты |

## 3. Формации (10 штук, по 2 на секту)

### Механика
- Вступление в секту = разблокировка 2 формаций **навсегда** (`prestige.unlockedFormations`)
- При перерождении: уровни формаций сбрасываются, разблокировка остаётся
- **Макс уровень формации = уровень Дао этой секты** (1 Дао = 1 уровень формации)
- 3 слота формаций (базовые), +1-2 от тел перерождения
- Формации качаются за камни (как сейчас)

### Распределение

**Нефритовая Чистота (Путь Воды)**
1. **Нефритовый Столб Ци** (qiPillar) — +10% ци за уровень. Макс 20
2. **Алтарь Прорыва** (breakthroughAltar) — +0.8% шанс прорыва за уровень. Макс 20

**Орден Алого Пламени (Путь Меча)**
3. **Пагода Закалки** (bodyPagoda) — +4% XP статов за уровень. Макс 20
4. **Арена Тысячи Клинков** (bladeArena) — +3% боевая мощь за уровень. Новая. Макс 20

**Секта Лунного Озера (Путь Пламени)**
5. **Алхимическая Печь** (alchemyFurnace) — +8% эффект пилюль за уровень. Макс 20
6. **Библиотека Мудрости** (wisdomLibrary) — +5% скорость техник за уровень. Макс 20

**Культ Бездны (Путь Убийства)**
7. **Круг Подавления Демонов** (wardCircle) — −5% шанс демона за уровень. Макс 20
8. **Алтарь Поглощения** (absorptionAltar) — +5% награды за опасные события за уровень. Новая. Макс 20

**Скрытая Секта (Путь Свободы)**
9. **Врата Тайного Царства** (realmGate) — −6% время экспедиций за уровень. Макс 20
10. **Зал Судьбы** (fateHall) — +4% кармы за уровень. Макс 20

### Убраны
- Озеро Фортуны (fortunePool, +удача) — удача качается через тренировку, формация не нужна

## 4. Изменения в текущей системе сект

### Бонусы секты → заменяются Дао
- Текущие `sect.bonuses = { qi: 0.10, breakthroughBonus: 0.05 }` → **УБРАТЬ**
- Вместо них: `sect.dao = { ... }` с бонусами/дебаффами по уровню Дао
- `getSectBonus()` → переписать: берёт бонусы из Дао уровня, не из `sect.bonuses`

### Предупреждение при смене секты
- При `leaveSect()`: модалка "Вы покидаете секту и меняете Путь Дао! Прогресс Дао этой секты сохранён, но активный Путь сменится."
- Дао текущей секты: `prestige.daoLevels[sectId] = max(текущий, сохранённый)`

### Пилюля как гейт прорыва → УБРАТЬ
- Пилюля больше не нужна для прорыва реалма
- Дао бар заменяет этот гейт

### Бар Дао
- Рядом с баром ци, появляется с реалма 3
- Показывает: "Постижение Дао: 45% (Путь Воды, ур. 2)"
- Цвет = цвет секты

### Таб формаций
- Показывать только разблокированные формации
- Заблокированные: "Вступите в [секту] чтобы разблокировать"
- Если формация разблокирована но уровень Дао < макс: "Макс уровень: X (уровень Дао)"

- Если ци ≥ 100% но Дао < 100%: кнопка disabled, тултип "Нужно постижение Дао"
- Если оба ≥ 100%: кнопка активна
