# Путь Культиватора — Контекст для Claude

## Что это
Инкрементальная idle-игра в жанре xianxia (cultivation). Vanilla JS, без фреймворков, один HTML-файл + подключаемые скрипты. Открывается через index.html в браузере. Версия: **0.66**.

Вдохновение: Realm Grinder (prestige-петля), Perfect Keystroke (культивация), классические сянься-новеллы.

## Структура проекта

```

  core.js       — REALMS (15), ELEMENTS (7), SPIRITUAL_ROOTS (7), тиры
  events/       — 178 событий, 12 шагов цепочек, 17 встреч (early/mid/late/sects/chains/cameos/rebirth/xianxia/artifact_find)
  adventures/   — 27 приключений (обычные, сюжетные и вознесения)
  sects/        — 5 сект (definitions + techniques + missions)
  prestige.js   — 13 тел перерождения, 14 кармических апгрейдов
  artifacts.js  — 6 тиров артефактов, 4 слота, заточка BDO-style, слияние PRI→PEN
  formations.js — 10 формаций (уровни на жизнь, разблокировка сохраняется)
  locations.js  — 7 тайных царств (экспедиции)

  state.js      — Объект `game` (всё состояние в одном глобальном объекте)
  formulas.js   — ВСЕ расчёты: qiPerSec, combatPower, breakthroughChance и т.д.
  lifecycle.js  — tick() [200ms], passYear() [5s], start/stop, reset()

  init.js       — addLog(), initGame(), DOMContentLoaded
```

## Ключевые паттерны кода

- **Глобальный объект `game`** — всё состояние. Никаких классов, ООП или модулей
- **Добавление нового поля**: state.js → lifecycle.js reset() → save.js getSaveableState() + applyLoadedState() с дефолтом
- **События**: EVENTS.push({id, text, type, condition(g), effect(g), weight?}) в файлах data/events/
- **Техники**: TECHNIQUES.push({...}) в data/techniques.js, эффекты суммируются через getTechBonus(key)
- **Бонусы**: getTechBonus() + getArtifactBonus() + getSectBonus() + getFormationBonus() — все суммируются в formulas.js
- **UI**: innerHTML-рендер по вызову (renderX()), updateTickUI() обновляет бары/числа без перерисовки
- **Загрузка скриптов**: data/* → save.js → game/* → ui/* (порядок важен, нет import/export)
- **Сохраняемое состояние**: только JSON-данные. Эффект финального приключения восстанавливается по индексу шага/выбора, pendingRebirth фиксирует уже начисленную карму. Остаток старого оплаченного Озарения выдаётся один раз после восстановления техник/тиров; новые покупки начисляют XP сразу.
- **Регрессии**: `npm test` — логика, миграции и ограничения экономики; `npm run test:browser` — интерфейс и настоящие перезагрузки (Playwright/Chromium); `npm run balance:simulate` — четыре жизни с фиксированным RNG без debug-бонусов.
- **Слухи**: adventureDiscovery, единый кулдаун и ожидание после доступности; сюжетные открытия помечены отдельно.
- **Экспедиции**: множители ресурсов фиксируются при старте; ци и годы медитации в пути не начисляются.
- **Кнопки**: рендеры используют deferUIRender(), чтобы не заменять нажатый контрол; кеш пилюль сохраняет DOM при неизменной разметке.
- **Техники**: эффект рассчитывается через getTechniqueEffectBonus(); множитель тира зависит от ключа эффекта (силовая кривая/поддержка). UI использует тот же расчёт.
- **Приключения**: getAdventureCheck() объединяет игровые и видимые условия; поздняя сложность фиксирована данными сюжета, не статами героя.
- **Карма**: prestige.karmaSpent — фактические платежи; общая накопленная карма = свободная + оплаченная. Скидки не увеличивают её. Прежние траты по каталогу не реконструируются.
- **Корень**: getMinRootTier()/getAvailableRoots() учитывают минимум тела/вознесения. Выбор однократный, ручные элементы только открытые, без дублей.
- **Пилюли секте**: donate_pills_sect завершается автоматически после нужной сдачи, обе выплаты и общий кулдаун сохранены.
- **Язык**: весь UI и данные на русском. Комментарии к коду — на русском или английском

## Игровая петля

```
tick() [200ms]  — авто-ци, XP статов (пассивно 15%, активный 100%), XP техник
passYear() [5s] — возраст++, доход камней, эпохи, мир.события, секта, экспедиции, смерть
triggerEvent() [15s] — цепочки → манхва → обычные события
autoSave [30s]
```

## Прогрессия

- 15 реалмов (0-14), каждый × 4 подуровня. Реалмы 0-9 смертные, 10-14 бессмертные
- Prestige через перерождение: карма → тела → кармические апгрейды → формации
- Дао: прогрессивные требования прорыва с Золотого Ядра; подходящая активность зависит от секты
- Секты (5 шт) → ранги → техники → задания → вклад
- Артефакты: генерация → заточка +0..+10 → слияние PRI→PEN → вознесение техник

## Правила работы

1. **Читай architecture.md и mechanics.md** перед крупными изменениями — там актуальная карта
2. **formulas.js — центр расчётов**. Не дублируй формулы в других файлах
3. **save.js** — при добавлении полей: state.js + reset() + getSaveableState() + applyLoadedState()
4. **Обновляй CHANGELOG.md** при значимых изменениях (текущая версия 0.66)
5. **Обновляй docs/** если меняешь механики, архитектуру или баланс
6. **Тестируй в браузере** — открой index.html, используй дебаг-панель (скорость x10/x50/x100)
7. **Не ломай сейвы** — applyLoadedState() должен мигрировать старые сохранения через дефолты
8. **Баланс**: смотри docs/game_balance.md для целевого пейсинга перед изменением чисел
9. **Бэклог**: актуальный список задач в `docs/backlog.md`. Отмечай `[x]` при завершении
